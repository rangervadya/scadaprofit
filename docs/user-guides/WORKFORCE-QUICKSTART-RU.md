# ScadaProfit 4.5.12 — рабочая система сотрудников

## Роли

- **Слесарь:** личный график адресов по датам; кнопки начала обхода, завершения обхода и возвращения в офис; отправка ручного эскиза и отдельная отправка фотографий дефектов.
- **Приёмщик:** назначение улиц/домов слесарям, единый список уведомлений-папок, проверка CAD-схем и фотографий дефектов, передача целой папки в заключение.
- **Руководитель:** планирование, контроль нажатых отметок по домам, создание аккаунтов, база логинов и сброс паролей.
- **Разработчик:** полный доступ и диагностика.

## Папки уведомлений

Один назначенный дом (одно задание) — одна папка. Например, «улица Ленина, д. 10». В папке вместе показываются все ручные эскизы и все комплекты фотографий дефектов, загруженные по этому заданию.

Каждый материал проверяется отдельно:

1. Схему можно открыть в CAD, исправить и сохранить. Кнопка в CAD возвращает в папку уведомлений; она не переносит отдельную схему в заключение.
2. Фотографии дефектов можно принять галочкой или вернуть слесарю с комментарием.
3. Если материал возвращён, слесарь отправляет исправленный вариант. Старый возвращённый отчёт помечается заменённым и не входит в итоговый пакет.
4. Когда все актуальные схемы и комплекты фотографий просмотрены и приняты, появляется единая кнопка **«Добавить всю папку в заключение»**.
5. При нажатии схемы папки привязываются к пункту 7 «Актуальные схемы, удостоверения и акты», а фото дефектов — к штатным фотополям Приложения 3 «Фото дефектного участка».
6. PDF/Word формируются только после того, как выбранные материалы действительно загружены в форму.

Перенос выполняется только для выбранного задания/адреса. Материалы других домов не подмешиваются. Самостоятельная форма заключения остаётся доступной из левого меню и не получает материалы автоматически.

## Назначение работ

В разделе «План работ» выбери слесаря, дату, улицу и перечисли дома (по одному на строку, до 100 домов за назначение). Каждому дому создаётся отдельное задание. Приёмщик и руководитель могут назначать работу; слесарь видит только свои назначения.

## Отметки слесаря и приватность

Трекер основан только на явно нажатых кнопках и времени события. GPS, координаты, фоновая геолокация и скрытое отслеживание не используются.

## Обновление

Из корневой папки, рядом с `compose.yaml`:

```bash
git pull --ff-only
docker compose build --no-cache app vdgo-backend
docker compose up -d --remove-orphans --no-deps --force-recreate app vdgo-backend
docker compose restart gateway
docker compose ps
```

Не удаляй постоянные тома `cad_jobs`, `ollama_data`, `vdgo_output`, `vdgo_uploads`, `vdgo_postgres_data`.
