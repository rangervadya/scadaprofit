# Права доступа ScadaProfit

Единая матрица — frontend/src/lib/permissions.mjs. Сервер импортирует её через backend/api/access-policy.js. Роль берётся из сессии. Неописанные API закрыты для всех ролей, кроме разработчика. Отказы записываются в журнал access_denied.

| Возможность | Слесарь | Приёмщик | Руководитель | Разработчик |
| --- | --- | --- | --- | --- |
| Рабочий стол и задания | Свои | Все | Все | Все |
| Заполнение заключения | Да | Да | Да | Да |
| PDF/Word | Нет | Да | Да | Да |
| Импорт/экспорт JSON заключения | Нет | Нет | Нет | Да |
| Схемы, архив, CAD | Нет | Да | Да | Да |
| Приёмка, назначение, смена слесаря, удаление задания | Нет | Да | Да | Да |
| Пользователи | Нет | Нет | Слесари и приёмщики | Все |
| Технические настройки | Нет | Нет | Нет | Да |

## Изменённые файлы

- permissions.mjs и permissions.d.mts — единый конфиг действий и разделов.
- backend/api/access-policy.js — маршруты, методы, журнал отказов, закрытие неизвестных API.
- backend/api/workforce-system.js — права до чтения ресурса, владение заданиями и вложениями, управление сотрудниками и заданиями, защищённые JSON API.
- Sidebar.tsx, main.tsx, Topbar.tsx — меню и прямые переходы по общему конфигу.
- TeamPage.tsx — отдельные разрешения на управление заданиями и сотрудниками.
- ConclusionPage.tsx и api.ts — JSON только разработчику, через сервер.
- Тесты структуры — проверка разрешений вместо локальных списков ролей.

Пример проверки:

```js
const permission = requiredPermission(req.method, req.path);
if (req.user?.role === 'developer' || hasPermission(req.user?.role, permission)) return true;
denyAccess(req, res);
```

## Ручная проверка

Все запросы выполняются с cookie проверяемого аккаунта.

- Слесарь — три пункта меню, форма без JSON и выпуска PDF. GET /api/workforce/tasks показывает свои задания. GET /api/workforce/tasks/<чужой-id> и POST этапа чужого задания возвращают 403. Настройки по URL запрещены. GET /api/library возвращает 403.
- Приёмщик — обзор, приёмка, выпуск заключения доступны. Нет пользователей, настроек, JSON. PATCH и DELETE /api/workforce/tasks/<id> разрешены. GET /api/workforce/users и GET /api/template возвращают 403.
- Руководитель — доступны сотрудники и производственные действия. PATCH аккаунта слесаря/приёмщика разрешён. Изменение аккаунта разработчика/руководителя запрещено. Настройки и JSON запрещены.
- Разработчик — доступны настройки и обе JSON-кнопки. Импорт подготовленного JSON и сохранение JSON проходят через POST /api/conclusion/json/import и POST /api/conclusion/json/export.
- Без сессии защищённый API возвращает 401. Параметр role в body/query не меняет права. Неизвестный API возвращает 403 обычным ролям. В журнале есть пользователь, роль, время и маршрут отказа.

## Трактовки документа

Первая строка таблицы объединяет рабочий стол и CAD. Применено отдельное явное требование: слесарю доступен рабочий стол со своими заданиями, CAD недоступен.

Полный доступ приёмщика к команде относится к производственным действиям. Управление сотрудниками доступно руководителю и разработчику согласно точечному требованию об отсутствии вкладки пользователей у приёмщика.

JSON заключения означает явный импорт/экспорт файла. Автосохранение введённых полей в браузере доступно всем, кто заполняет заключение. Передача формы PDF-сервису не является экспортом JSON.
