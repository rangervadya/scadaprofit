# Документация ScadaProfit

- `user-guides/` — обзор на русском, инструкции для команды, руководство CAD.
- `deployment/` — Docker, установка модели и диагностика развёртывания.
- `development/` — описание пайплайна, JSON, промптов и требований к примерам.
- `releases/` — история версий и изменения релизов.
