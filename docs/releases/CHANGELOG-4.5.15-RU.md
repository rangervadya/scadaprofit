# ScadaProfit 4.5.15 — интеграция нового frontend

- Полностью заменён активный интерфейс на загруженный единый React SPA.
- Все пользовательские разделы (рабочий стол, заключение, схемы, CAD, архив, команда и настройки) собраны в одном `frontend/` и одном `app`-контейнере.
- Корневой URL `/` перенаправляет на `/vdgo/`; старые HTML-закладки перенаправляются на соответствующие маршруты SPA.
- Слесарь видит личный рабочий стол и команду; разделы заключения, схем, архива, CAD и настроек скрыты и защищены role guard.
- Статические SPA-файлы доступны для показа формы входа, а VDGO API и генерация PDF/Word по-прежнему проходят отдельную серверную проверку сессии и роли.
- Сохранены основной Node.js backend, Python CAD/recognition engine, workforce API, отдельный VDGO backend, PostgreSQL, шаблоны документов, Docker volumes и Nginx gateway.
- Старые multi-page UI файлы сохранены только как тестовые fixtures и не раздаются пользователям.
- Исправлены Dockerfile, Nginx и документация под единый frontend workspace.
