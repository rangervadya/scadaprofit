# ScadaProfit 4.5.11 — папки уведомлений по адресу

- Уведомления приёмщика объединены в адресные папки по ID задания: ручные схемы и комплекты фотографий дефектов одного дома показываются вместе.
- Каждая схема и каждый комплект фотографий принимаются/возвращаются отдельно; перенос в заключение разрешён только после просмотра и принятия всех актуальных материалов.
- Добавлена единая атомарная команда переноса папки: схемы привязываются к пункту 7, дефектные фотографии — к Приложению 3. Старые индивидуальные API-переносы отклоняются.
- CAD-кнопка переименована в «Сохранить и вернуться в папку»: она сохраняет редактирование и возвращает приёмщика к нужному адресу, но не переносит схему по отдельности.
- Возвращённый и заменённый отчёт исключается из актуального содержимого папки.
- Обновлены кеш-версии страниц, README, инструкции GitHub и Docker.
- Шрифты Carlito больше не хранятся как бинарные файлы в репозитории: VDGO Docker image устанавливает пакет `fonts-crosextra-carlito` из Debian.

Проверки: `npm --prefix backend run check` выполняет JS-тесты workforce/CAD и Python-тесты движка. Отдельно проверяется PDF regression test для VDGO. Docker runtime на целевом сервере необходимо проверять после развёртывания.
