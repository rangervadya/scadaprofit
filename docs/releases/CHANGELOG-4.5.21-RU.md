# ScadaProfit 4.5.21

- Восстановлена целостная структура основного Node.js API и Python CAD-движка.
- Использован frontend из предоставленного `frontend.tar.xz`; сохранены его компоненты и стили.
- Возвращён отдельный редактор таблиц УЗТ; структура и нумерация разделов формы сохранены как в выбранном frontend.
- Перенесены совместимые исправления ролей, входа, адресных папок и перехода из приёмки в заключение.
- Сохранены JSON-импорт, заполнение существующей таблицы дефектов, фотографии для Приложения 3 и схемы для Приложения 2.
- `compose.yaml` остаётся единственной основной конфигурацией Docker Compose.

## Обновление

Перед обновлением сохраните `.env` и сделайте резервную копию постоянных Docker-томов. Не выполняйте `docker compose down -v`.
