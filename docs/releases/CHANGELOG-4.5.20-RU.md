# ScadaProfit 4.5.20

- Исправлен импорт подготовленного JSON: поля определяются не только по HTML-именам, но и по русским подписям внутри объектов с непрозрачными ID контролов/ячеек.
- Обработаны вложенные `field`/`descriptor`/`control` метаданные, обёртки значений и словари ячеек таблиц. Импорт охватывает существующие поля, дефекты, арматуру, обе таблицы УЗТ и таблицу расчёта ресурса.
- Устранено отбрасывание обычных скалярных полей `resource_working_pressure` и `resource_calculated_by`; исключаются только реальные индексированные ячейки таблицы ресурса.
- Принятые материалы слесарей остаются привязаны к существующим разделам заключения: описание дефекта — в действующую таблицу дефектов; фотографии — в существующие фотослоты/Приложение 3; CAD — в существующее размещение схем/Приложение 2.
- Названия, нумерация, расположение и исходный PDF-шаблон разделов заключения не менялись.
- В `/health` версия релиза и backend теперь берётся из констант текущей сборки.
