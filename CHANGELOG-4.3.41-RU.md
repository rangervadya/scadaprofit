# Изменения ScadaProfit 4.3.41

## Исправлено

- Убрано автоматическое открытие режима скелетизации. Он преобразует все тёмные штрихи, включая текст и символы, и не является распознанной сетью труб.
- Введён режим просмотра исходной фотографии, который выбирается по умолчанию, пока автоматическая CAD-реконструкция не проходит проверку.
- Добавлена оценка готовности CAD по открытым окончаниям, пересечениям, классификации условных обозначений и привязке размеров.
- Для CAD-черновика, не прошедшего проверки, отключён чистовой экспорт SVG/DXF/PDF. Диагностические векторные артефакты остаются доступны в отдельных режимах.
- Добавлен объект `cadReadiness` в JSON-диагностику.
- Печать в PDF из режима исходника печатает именно исходную фотографию.

## Результат последней диагностики пользователя

- 428 сегментов, 406 открытых окончаний (94,9%).
- 173 неоднозначных пересечения (40,4% от числа сегментов).
- 0 из 11 символов классифицированы.
- 1 из 8 размеров привязан к объекту.

При таких данных автоматическая CAD-схема объективно не готова. Теперь UI не будет выдавать набор сырых линий за чистовой чертёж.

## Не затронуто

VDGO, `vdgo/`, `compose.yaml`, Ollama, PostgreSQL, Nginx/gateway, Docker volumes, настоящий `.env` и процессы других приложений.
