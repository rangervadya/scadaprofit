ScadaProfit 4.5.3 — исправление EXDEV при отправке отчёта слесарём

Исправлено:
- При сохранении ручного эскиза больше не выполняется прямой rename из временного каталога Multer (/tmp) на постоянный том (/data).
- Файл копируется во временный файл в каталоге отчёта, затем переименовывается внутри одного файлового раздела.
- Временная загрузка удаляется после успешного сохранения; файл отчёта остаётся с правами 0600.
- Добавлен регрессионный тест для случая, когда источник и папка отчёта находятся на разных файловых системах.

Обновление:
  docker compose build app
  docker compose up -d --no-deps app
  docker compose restart gateway

Постоянный том cad_jobs и данные сотрудников удалять не нужно. Интерфейс и рабочий процесс не изменены.
