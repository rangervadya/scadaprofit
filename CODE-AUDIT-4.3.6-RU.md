# Технический аудит 4.3.6

## Изменения интерфейса

- Конкурирующие `joinCandidates` группируются по общему endpoint node через `conflicting_nodes`.
- Для группы показываются candidate IDs, оценка каждого варианта и разница двух лучших оценок. Оценка явно обозначена как эвристический рейтинг, а не вероятность.
- Кнопка «Сравнить» рисует все варианты группы поверх исходного изображения; «На схеме» выделяет один вариант.
- Отдельная кнопка «Подтвердить» требует явного `window.confirm` для подтверждения пары и перечисляет альтернативы, если они есть.

## Сохранение на сервере

- `POST /api/jobs/:jobId/connections` принимает два узла и, для алгоритмического кандидата, его ID.
- Сервер проверяет UUID задания, наличие пары и соответствие ID candidate; конкурирующий кандидат требует `confirmAlternative: true`.
- Для candidate-пары сервер проверяет, что оба узла ещё открытые (`degree === 1`) и что такого ребра ещё нет.
- Добавляется ребро `source: manual`, запись в `confirmedConnections`, увеличиваются степени узлов, а альтернативы, использующие потреблённые концы, удаляются из списка.
- `graph.json` заменяется атомарно через временный файл в том же каталоге.
- `GET /api/jobs/:jobId/graph` восстанавливает граф и URL диагностических ресурсов.
- После анализа URL получает `?job=<uuid>`; загрузка этой ссылки восстанавливает сохранённое задание и подтверждённые соединения.

## Хранение заданий

- `DATA_DIR` изменён на `/data/cad-reconstruction-jobs`.
- Compose подключает named volume `cad_jobs`.
- Dockerfile заранее создаёт каталог с владельцем `node`, чтобы пустой named volume наследовал доступ для непривилегированного процесса.
- Инструкция установки содержит однократный перенос существующих заданий из `/tmp/cad-reconstruction-jobs` до пересоздания контейнера 4.3.5.

## Экспорт

Ручные рёбра имеют `source: manual`, поэтому текущие функции `isPrimaryCadEdge()` / `cleanCadChains()` включают их в основной векторный слой; JSON содержит edge и `confirmedConnections`. Сомнительные кандидаты по-прежнему не применяются без явного подтверждения.

## Ограничение инженерной достоверности

Рейтинг J2 (94,3) выше J5 (91,0), но это не означает 94,3% вероятности правильного соединения. Версия показывает, сравнивает и сохраняет явный выбор пользователя; автоматического разрешения конкурирующих соединений нет. Правильность трубной топологии должна подтверждаться исходным чертежом.
