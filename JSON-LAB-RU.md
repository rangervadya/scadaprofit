# Лаборатория Qwen JSON — инструкция

## Назначение

Это отдельный измерительный контур, который разделяет распознавание и построение. Он помогает ответить на вопрос: Qwen неверно определил точки/соединения, или визуализатор неверно прочитал уже правильный JSON?

## Этап 1 — фото → граф

Верхняя форма принимает фото. Кнопка «Извлечь точки и линии с фото» вызывает `POST /api/qwen-extract` с выбранной моделью Ollama. В запросе отправляется vision prompt. В ответе API возвращаются:

- `rawContent` — дословный `message.content` Ollama;
- `parsed` — JSON после `JSON.parse`;
- `doneReason`, `evalCount`, `thinking`, `model`;
- `parseError`, если модель не вернула разбираемый JSON.

Ожидаемая форма графа: `points: [{id,x,y}]`, `lines: [{from,to}]`, `warnings`. Координатное пространство 1000 × 650; x слева направо, y сверху вниз. Каждый поворот должен быть отдельной точкой.

## Этап 2 — граф → путь

Редактор входного JSON можно поправить вручную. Поля START_ID и END_ID задают начало/конец маршрута. Кнопка вызывает `POST /api/qwen-route` с большим редактируемым промптом и входным JSON. Ожидается JSON с ключами `status`, `points`, `lines`, `path`, `total_length`, `warnings`.

## Соседняя визуализация

SVG-элементы создаются в браузере непосредственно из координат и связей JSON. Стрелка показывает направление `from` → `to`. Индекс сегмента и кнопки предыдущего/следующего шага позволяют проверить последовательность. При `needs_review`/`impossible` исходный граф остаётся на холсте; неподтверждённый маршрут не маскируется.

## Независимая проверка

Backend повторно проверяет уникальность id, конечность и границы координат, существование точек у каждого ребра, самосвязи, дубликаты, наличие каждого ребра последовательности `path` и пересчитывает `total_length`. Проверка не заменяет инженерную экспертизу и не исправляет ответ молча.

## Как диагностировать

- Неверные координаты или отсутствующие линии уже в `rawContent` → распознавание Qwen.
- `rawContent` верный, но `parsed` отличается → JSON parsing/normalization.
- `parsed` верный, но SVG не совпадает с координатами → браузерный визуализатор.
- Graph верный, но Qwen path неверен или `needs_review` → маршрутный промпт/логика модели.
- Путь визуально верный, но `localValidation.valid=false` → ошибка связей/порядка/длины в ответе Qwen.

Важное ограничение: на фото с разветвлениями часто нет единственного пути от первой к последней точке. В таком случае `needs_review` — правильный ответ, пока пользователь не выберет конкретные START_ID и END_ID.
