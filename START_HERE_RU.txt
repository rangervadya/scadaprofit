ВДГО — версия 5.3.7

WINDOWS (самый простой способ)
1. Распакуйте весь ZIP в обычную папку, например C:\VDGO\.
2. Установите Python 3.12+ и Node.js 24+ (при установке Python включите Add Python to PATH). Интернет понадобится при первой установке библиотек.
3. Дважды щёлкните install_and_run.bat.
4. Если Docker Desktop уже установлен и запущен, приложение запустится через Docker: откройте http://localhost:8080.
   Иначе запустится локально: откройте http://127.0.0.1:5173.
5. Оставьте открытыми окна запуска, пока работает приложение.

MACOS
1. Распакуйте архив.
2. Откройте Terminal, перейдите в папку проекта и выполните:
   chmod +x start_mac_local.command
   ./start_mac_local.command
3. Откройте http://127.0.0.1:5173 и не закрывайте Terminal во время работы.

LINUX
1. Перейдите в распакованную папку проекта.
2. Выполните: chmod +x start_linux.sh && ./start_linux.sh
3. Откройте http://127.0.0.1:5173.

DOCKER (если не используется автоматический запуск)
1. При необходимости скопируйте .env.example в .env и измените пароль базы данных.
2. Из корня проекта выполните: docker compose up --build
3. Откройте http://localhost:8080.
4. Остановить: Ctrl+C. Для фонового запуска используйте docker compose up --build -d; остановка — docker compose down.

ЕСЛИ НЕ ОТКРЫВАЕТСЯ
- Убедитесь, что установлены Python 3.12+ и Node.js 24+ либо запущен Docker Desktop.
- При первом запуске требуется интернет, чтобы загрузить зависимости Python/npm или собрать Docker-образы.
- Не распаковывайте проект поверх старой версии; используйте отдельную папку.
