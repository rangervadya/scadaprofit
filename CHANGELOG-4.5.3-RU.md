# ScadaProfit 4.5.3 — исправление загрузки ручных эскизов

- Исправлена ошибка `EXDEV: cross-device link not permitted` при отправке ручного эскиза слесарем.
- Вместо прямого `rename()` временного файла из `/tmp` в постоянный каталог `/data` файл копируется во временный staging-файл рядом с целевым каталогом и затем атомарно переименовывается на том же файловом разделе.
- После успешного сохранения временный файл Multer удаляется. Если очистить исходный временный файл не удалось, успешно сохранённый отчёт не считается ошибочным.
- Файлы эскизов сохраняются с правами `0600`; логика ролей, CAD, уведомлений, заключения и меню не менялась.
- Добавлен тест реального межфайлового сохранения между разными файловыми системами.
