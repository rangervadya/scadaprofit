# Обновление CAD Sketch Converter до 4.3.11

## Что меняется

1. **Рукописный OCR списков:** соседние строки отправляются в Qwen парами. Если ответ неполный, confidence ниже 70 или строка не читается, эта строка автоматически отправляется на прежнее индивидуальное распознавание. При ошибке парного запроса обе строки также переходят на индивидуальный путь. Порог итогового подтверждения отдельной строки остаётся 58.
2. **Компактные OCR-координаты:** bbox передаются как `[x1,y1,x2,y2]`; координаты преобразуются в прежний внутренний формат без изменения масштаба и исходных пикселей.
3. **Трассировка труб:** Qwen просят возвращать одну полилинию для непрерывного пути с вершинами на видимых поворотах. Ветви разделяются в точках развилки; разрывы и неоднозначные стыки не достраиваются. Парсер и обрезка плиток поддерживают до 64 точек в одной полилинии.
4. Модель Qwen3-VL 4B, сетка 3×3, качество изображения, размеры плиток, лимиты токенов и последовательный порядок запросов не уменьшаются.

## Какие файлы заменить в GitHub

- `processor.py`
- `tests/test_engine.py`
- `server.js`
- `package.json`

Остальные файлы проекта менять не требуется. Положите тест в каталог `tests/`.

## Проверка и установка на сервере

После Commit changes в ветке `main`:

```bash
cd /opt/scadaprofit

git pull --ff-only origin main

sudo docker compose config --quiet

sudo docker compose build app

sudo docker compose up -d --no-deps app

sudo docker compose ps

curl -sS http://127.0.0.1:3001/api/health
```

В health ожидается `version: 4.3.11` и доступная модель Ollama. Команда `--no-deps app` не перезапускает Ollama. Не выполняйте `docker compose down -v` и не удаляйте тома.

## Проверки в этой сборке

`npm run check`: синтаксис Node.js, компиляция Python и 70 unit/regression tests — успешно.

## Важно о скорости и качестве

Изменения уменьшают избыточность ответов и повторный prompt-prefill, но не являются измерением фактического ускорения на GTX 1060. Скорость и качество Qwen нужно сравнить на том же чертеже после обновления. Парные OCR-строки с сомнительной уверенностью перечитываются по одной; неразборчивые и неоднозначные элементы не повышаются автоматически в подтверждённые.
