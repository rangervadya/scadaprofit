ПРОФИТ / ScadaProfit 4.3.44
Помощник восстановления эскиза слесаря

ПОРЯДОК РАБОТЫ
1. В разделе «Распознавание эскизов» выберите адрес и загрузите фото.
2. Если снимок боковой, укажите поворот 90/180/270 градусов. Для правильной ориентации по умолчанию оставьте «Авто».
3. Запустите локальный анализ Qwen + Tesseract + OpenCV.
4. Откройте созданный проект в CAD-редакторе. Для проектов эскиза включаются оранжевые кандидаты маршрутов.
5. Сверьте каждый маршрут с подложкой. Выберите линию и нажмите «Подтвердить линию», только если это действительно труба. Удалите шумовые штрихи.
6. Для неизвестного условного знака выберите знак на листе и укажите его точный тип в свойствах.
7. Исправьте углы, узлы, размеры, номера и группы стояков. Заполните адрес и сведения о составителе.
8. Экспортируйте SVG/DXF после инженерной проверки.

ВАЖНО
Оранжевые линии — гипотезы алгоритма, а не подтверждённые трубопроводы. Автоматическое распознавание не гарантирует правильность соединений и оборудования. Перед использованием в техническом заключении схему обязан проверить специалист.

УСТАНОВКА ЧЕРЕЗ GIT
Локально: git add -A; git commit -m "ScadaProfit 4.3.44 sketch assistant"; git push origin HEAD
На сервере: git pull --ff-only; docker compose build app; docker compose up -d --no-deps app
Другие сервисы не пересоздавайте. Не применяйте docker compose down -v.

ПРОВЕРКИ РАЗРАБОТКИ
16/16 тестов CAD-редактора и 167/167 Python-тестов прошли. На одном сохранённом тестовом графе импорт сформировал 43 основных маршрута, 136 кандидатов и 17 неизвестных знаков для ручной классификации. Эти показатели относятся только к тестовому файлу и не гарантируют такие же числа на другом эскизе.
