# Обновление до Two Mask Lab 3.3.0

Распакуй архив в `/opt/scadaprofit` поверх предыдущей версии, сохранив `.env`, затем выполни:

```bash
cd /opt/scadaprofit
docker compose config --quiet
docker compose build --no-cache app
docker compose up -d --force-recreate app
docker compose exec app node -p "require('./package.json').version"
```

Ожидаемая версия: `3.3.0`. Не используй `docker compose down -v`: это не нужно, а том Ollama сохранится.

## Работа с подписями

После распознавания в блоке «Исправить распознанные цифры и буквы» для каждой OCR-области доступны две независимые галочки:

- «Убрать рукопись» — закрыть исходный рукописный фрагмент из векторного слоя линий.
- «Печатать» — вывести значение из текстового поля печатным шрифтом в чистом SVG.

Распознанный текст из Tesseract не печатается автоматически, поскольку рукописные цифры могут распознаваться неправильно. Проверь миниатюру, исправь значение и только затем включи «Печатать». После правок нажми «Применить подписи». OCR повторно не запускается.
