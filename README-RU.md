## Принцип работы
- Основной CAD-лист строится по отобранным CAD-путям OpenCV (`cad_include`); семантические маршруты Qwen сохраняются отдельно для проверки.
- Qwen получает отдельную задачу: пропускать цифры, подписи, размерные линии, выноски, стрелки, засечки и символы арматуры; возвращать только осевые линии труб, углы и реальные ответвления.
- Рукописный OCR выполняется на четырёх перекрывающихся увеличенных фрагментах изображения, чтобы мелкие размеры и цифры читались крупнее.
- OCR-боксы умеренной уверенности также маскируют штрихи символов от геометрического детектора, даже когда текст пока не подтверждён для экспорта. Продолжение трубы через такую область проверяется отдельно и сохраняется.
- Неотобранные векторные кандидаты OpenCV остаются в графе и замороженном слое DXF `DETAIL_REVIEW`; маршруты Qwen сохраняются на отдельном замороженном слое `QWEN_REVIEW`.
- Основной слой `PIPE_MAIN` не зависит от наличия Qwen-маршрутов: он строится из выбранного геометрического графа OpenCV. Qwen используется как независимая подсказка; неотобранные фрагменты остаются в `DETAIL_REVIEW`.
- Увеличено упрощение полилиний для устранения мелкой дрожи рукописных штрихов.

## Исправления 4.2.2
- Чистый лист больше не экспортирует целые связные компоненты целиком: граф разбивается на непрерывные пути между узлами и терминалами.
- Короткие боковые штрихи символов, размерные риски и изолированные пометки не попадают на основной CAD-лист.

- Добавлено мягкое упрощение ломаных Ramer–Douglas–Peucker для устранения мелкой дрожи пера без удаления реальных поворотов.
- Повторные границы одного толстого штриха от LSD/Hough объединяются; отдельные параллельные линии с белым промежутком не склеиваются.

## Как устроен движок

1. OpenCV нормализует освещение и формирует диагностическую маску чернил.
2. OpenCV выделяет геометрические отрезки; граф отбирает и собирает основные CAD-пути. Qwen3-VL предлагает независимые семантические маршруты для отдельной проверки.
3. Отдельный OCR-проход Qwen3-VL читает увеличенные фрагменты; Tesseract дополняет его. Надписи экспортируются как CAD TEXT, а найденные текстовые области исключаются из линейных кандидатов.
4. Концы сегментов объединяются в узлы только при расстоянии до 4,5 px.
5. Геометрические пересечения не становятся соединениями автоматически.
6. Короткие соосные разрывы перечисляются как предложения; пользователь подтверждает каждый.
7. Отобранные пути OpenCV формируют `PIPE_MAIN`; неотобранные кандидаты остаются в `DETAIL_REVIEW`. Узлы можно перемещать, а пользовательские соединения — добавлять вручную.
8. Текущий граф экспортируется в SVG, DXF и JSON; PDF получается через диалог печати браузера.

## Ограничения

Это экспериментальный, несертифицированный распознаватель. Qwen3-VL может пропускать ответвления, неточно ставить точки поворота или ошибаться в чтении цифр. OpenCV LSD/Hough всё ещё находит размерные линии, стрелки и части символов, но они хранятся отдельно как кандидаты для проверки. Качество отбора OpenCV зависит от контраста и структуры исходного рисунка; Qwen-маршруты являются дополнительными подсказками, а не подтверждённой геометрией. Перед использованием в проектировании необходимо сверить топологию, все размеры и подписи с оригиналом.

## Локальный запуск

Требуются Node.js 20+, Python 3.11+, Ollama с моделью `qwen3-vl:4b`, Tesseract (`rus` и `eng`) и пакеты из `requirements.txt`. Без Ollama доступен только черновой геометрический режим; он не должен считаться полноценным CAD-распознаванием.

```bash
npm install
python3 -m pip install -r requirements.txt
npm start
```

Открой `http://localhost:3000`.

## Docker / Ubuntu

См. `UPDATE-RU.md`. По умолчанию приложение доступно на `http://SERVER-IP:3001`.
Для загрузки модели в локальный контейнер Ollama выполни один раз:

```bash
docker compose exec ollama ollama pull qwen3-vl:4b
```

При использовании Ollama, уже установленного на хосте, запускай Compose с `-f compose.yaml -f compose.host-ollama.yaml` и проверь `OLLAMA_CHAT_URL` в конфигурации.

При обновлении поверх `/opt/scadaprofit` сохраняй `.env` и именованный том Ollama. Не используй `docker compose down -v`.

## Файлы результата

- `graph.json` — кандидаты, узлы, пересечения, предложения соединений и OCR-аннотации.
- `overlay.png` — диагностическое наложение кандидатов на фотографию.
- `ink-mask.png` — исходная общая маска чернил. Подтверждённые текстовые штрихи фильтруются на этапе построения линейных кандидатов, а не изменением исходной маски.
- `clean.svg` / `drawing.dxf` — предварительный CAD-лист: отобранные пути OpenCV на `PIPE_MAIN`, маршруты Qwen на замороженном `QWEN_REVIEW`, неотобранные кандидаты OpenCV на замороженном `DETAIL_REVIEW`, уверенные подписи на `VERIFIED_TEXT`.
