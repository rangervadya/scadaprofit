# ScadaProfit 4.3.25

Обновление 4.3.25 собрано как накопительное поверх предоставленного проекта 4.3.23. Оно сохраняет улучшения 4.3.24: очередь загрузки схем домов, топологическую обработку, отдельный слой кандидатов на проверку, ручной CAD LPGCad R1 и экспорт SVG/DXF.

Добавлен необязательный Yandex Cloud AI: Yandex Vision OCR для рукописных подписей и мультимодальная Qwen3.6-35B-A3B для предложений трубных маршрутов. Локальные Qwen3-VL и Tesseract не удалены и продолжают работать. Облачный провайдер по умолчанию выключен; его можно отдельно настроить, протестировать и при необходимости удалить без затрагивания локальных движков.

Облачные маршруты проверяются по исходным пикселям и геометрии OpenCV; непроверенные подписи и сомнительные соединения остаются на ручной проверке. API-ключ хранится на сервере в закрытом файле внутри существующего тома данных ScadaProfit и не возвращается браузеру.

Обновление ограничено файлами из `UPDATE-MANIFEST-4.3.25.txt`. `vdgo/`, Compose, Nginx, PostgreSQL и тома не изменяются. Установка и тест Yandex описаны в `UPGRADE-GIT-4.3.25-RU.md`. Проверка реального API требует ключа и IAM-ролей пользователя; серверная Docker-сборка после обновления ещё должна быть выполнена.
