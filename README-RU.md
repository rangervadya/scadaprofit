# CAD Reconstruction Engine 4.0.0

Локальный экспериментальный конвейер для переноса рукописной инженерной схемы в редактируемый граф линий и векторный лист.

## Что изменено относительно Two Mask Lab

Старый принцип «OCR-бокс вырезает пиксели из маски линий» удалён. Геометрия и текст теперь независимы:

1. OpenCV нормализует освещение и строит общий набор пикселей чернил.
2. LSD и Hough находят кандидаты отрезков.
3. OCR создаёт отдельные текстовые аннотации. Совпадение с OCR-боксом только помечает кандидат как `text_or_dimension`; сам отрезок не удаляется.
4. Концы отрезков объединяются в узлы только при расстоянии не более 4.5 px. Координаты отрезков привязываются к общей координате узла, поэтому подтверждённые соседние сегменты визуально сходятся.
5. Геометрические пересечения не объединяются автоматически.
6. Короткие соосные разрывы перечисляются как `joinCandidates`; пользователь подтверждает каждое соединение отдельно.
7. В браузере можно скрыть шумные кандидаты, перемещать узлы, соединять выбранные узлы, редактировать OCR-подписи и экспортировать SVG/DXF/JSON. Печать листа позволяет сохранить PDF.

## Что это не делает

Это не готовый автоматический распознаватель трубопроводов и не сертифицированный CAD-конвертер. LSD/Hough обнаруживают линейные штрихи — включая размерные линии, стрелки и некоторые символы. OCR не всегда читает рукописный текст. Поэтому интерфейс показывает **кандидаты** и требует проверки. В частности, фильтр «Основные» скрывает короткие фрагменты и кандидаты, попавшие в OCR-боксы, но не удаляет их из исходного JSON: «Показать все» возвращает полный набор.

Qwen/Ollama сохранён как отдельный сервис в Compose и его именованный том не меняется, но геометрический конвейер 4.0.0 от Ollama не зависит и не вызывает её. Это намеренно: модель не должна придумывать координаты труб.

## Запуск локально

Требуются Node.js 20+, Python 3.11+, Tesseract с `rus` и `eng`, пакеты из `requirements.txt`.

```bash
npm install
python -m pip install -r requirements.txt
npm start
```

Откройте `http://localhost:3000`.

## Docker / Ubuntu

См. `UPDATE-RU.md`. По умолчанию приложение доступно на `http://SERVER-IP:3001`.

## Файлы результата

- `graph.json` — исходные кандидаты сегментов, узлы, пересечения, предложения соединений и OCR-аннотации.
- `overlay.png` — диагностическое наложение кандидатов на фото.
- `ink-mask.png` — вспомогательная маска всех найденных чернил; она не разделяется по OCR-боксам.
- `clean.svg` / `drawing.dxf` — предварительный серверный экспорт.
- Экспорт в браузере использует текущие изменения графа и проверенные текстовые подписи.

## Проверка

```bash
npm run check
```

Тесты проверяют снаппинг концов в общий узел, запрет автоматического соединения пересечений, независимость OCR от геометрии, SVG и DXF-экспорт.
