# CAD Reconstruction Engine 4.3.6

Релиз 4.3.6 улучшает ручную проверку конкурирующих соединений и сохраняет явные подтверждения пользователя в `graph.json` на сервере. Для общего конечного узла (например, N565) интерфейс показывает группу альтернатив, оценку каждого кандидата и разницу рейтингов; кнопка «Сравнить» подсвечивает все варианты на исходном чертеже, а «На схеме» — отдельную пару. Оценка является ранжирующим показателем, не вероятностью.

Каталог заданий находится на постоянном Docker-томе `cad_jobs` и сохраняется при пересоздании контейнера. Для переноса старых заданий 4.3.5 используйте инструкцию установки. Подтверждение требует явного действия пользователя. Сервер проверяет candidate ID и узлы, добавляет ручное ребро, записывает `confirmedConnections`, убирает конфликтующие альтернативы и атомарно сохраняет `graph.json`. URL задания получает параметр `?job=<uuid>`; при повторном открытии страница восстанавливает граф и подтверждённые соединения. Ручные рёбра входят в `PIPE_MAIN` при экспорте SVG/DXF и остаются отмеченными как `source=manual` в JSON.

Версия сохраняет 45-минутный тайм-аут Python и потоковые логи 4.3.4, а также диагностику коротких и неоднозначных концов 4.3.5. Автоматического соединения кандидатов по рейтингу нет. Перед инженерным использованием обязательно сверяйте трубопроводы, пересечения, размеры и подписи с оригиналом.

Установка: `INSTALL-4.3.6-RU.md`. Публикация через Git: `UPGRADE-GIT-4.3.6-RU.md`.
