# CAD Reconstruction Engine 4.3.7

Релиз 4.3.7 исправляет чрезмерно строгую классификацию сложных трубопроводных компонентов. Раньше многоветвевые маршруты могли оставаться в `DETAIL_REVIEW` только из-за узла степени 6–8 или из-за общего фильтра плотных символов, даже когда компонент имел несколько ветвей, сильную поддержку исходными чернилами и низкое перекрытие OCR.

**Что изменено:**
- Добавлен критерий `topology_network_candidate` для крупных связных многоветвевых компонентов: не менее 8 рёбер, 2–7 ветвящихся узлов, суммарная длина от 135 px, максимальная степень узла до 8, ограниченная плотность/повороты, средняя поддержка чернилами от 0.40 и низкое OCR-перекрытие.
- Плотный компонент больше не отклоняется общим фильтром `dense_symbol_cluster`, если он одновременно прошёл независимую проверку связного/углового маршрута. Для такого исключения дополнительно требуются несколько рёбер, ветвление, достаточная длина, низкие OCR и turn density.
- В JSON добавлены `mean_ink_support`, `max_edge_ocr_overlap`, `short_edge_ratio`, `topology_network_candidate` и новые счётчики в `summary`.
- В статусе интерфейса отображаются число структурных компонентов, число многоветвевых сетей и количество их рёбер, попавших в `PIPE_MAIN`.

Изолированные длинные линии не продвигаются автоматически. Текстовые/размерные компоненты с высоким OCR-перекрытием остаются вне `PIPE_MAIN`. Кандидаты на стыковку и пересечения не объединяются автоматически. Оценка геометрии не является доказательством технологического соединения: обязательно проверяйте экспорт DXF по оригиналу перед монтажом или изготовлением.

Установка поверх 4.3.6: `INSTALL-4.3.7-RU.md`. Сохраняйте `.env`, `.git` и Docker-том `cad_jobs`; не используйте `docker compose down -v`.
