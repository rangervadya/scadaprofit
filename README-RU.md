# ScadaProfit 4.3.28

Версия заменяет облачную интеграцию Yandex на необязательный мультимодальный провайдер OpenRouter с бесплатной моделью `nvidia/nemotron-3.5-super-vl:free`. Модель используется для OCR рукописных подписей и предложения маршрутов труб по фотографии. Все маршруты дополнительно проверяются по исходным чернилам и топологии; сомнительные подписи и соединения остаются на ручную проверку.

Локальный Ollama Qwen3-VL сохранён как резерв, Tesseract — как дополнительный OCR. OpenRouter выключен по умолчанию и активируется только после сохранения ключа и включения пользователем. API-ключ хранится в закрытом томе данных ScadaProfit, не возвращается браузеру и не попадает в Git.

Бесплатные модели OpenRouter сейчас ограничены 50 запросами в сутки и 20 в минуту; полноценная проверка/обработка использует два облачных запроса (OCR и трассировка). Неуспешные обращения могут расходовать дневной лимит. Бесплатный endpoint NVIDIA может сохранять запросы и изображения для улучшения сервиса. Не отправляйте чертежи с адресами, ФИО, телефонами и другой конфиденциальной информацией; для первого теста используйте обезличенную копию.

Обновление изменяет только основной ScadaProfit и его тесты/документацию. `vdgo/`, `compose.yaml`, Nginx, PostgreSQL и Docker volumes не изменяются. Инструкция — `UPGRADE-GIT-4.3.28-RU.md`. Реальный API-вызов и сборка Docker должны быть проверены после установки с ключом пользователя.
