# ScadaProfit 4.3.29

Версия добавляет MOSS-VL (`moss-vl-1.0`) как основной облачный мультимодальный провайдер для OCR рукописных подписей и предложения маршрутов труб. Официальный MOSS API принимает локальное изображение через временный файл (`/v1/files`), затем анализирует его через `/v1/responses`; ScadaProfit удаляет загруженный API-файл после каждого запроса. Все предложенные маршруты проверяются по исходным чернилам и топологии; сомнительные подписи и соединения остаются на ручную проверку.

Локальный Ollama Qwen3-VL сохранён как резерв, Tesseract — как дополнительный OCR. MOSS включается только после сохранения ключа и включения пользователем. Ключ хранится в закрытом томе данных ScadaProfit, не возвращается браузеру и не попадает в Git. OpenRouter сохранён как дополнительная настройка, но не вызывается, пока активен MOSS.

На странице MOSS-VL сейчас указано временно бесплатное использование (0 кредитов); это не гарантия постоянной бесплатности. API-обращения загружают исходную фотографию к MOSS для обработки. Для первого теста используй обезличенную копию без адресов, ФИО, телефонов и другой конфиденциальной информации.

Обновление изменяет только основной ScadaProfit и его тесты/документацию. `vdgo/`, `compose.yaml`, Nginx, PostgreSQL и Docker volumes не изменяются. Инструкция — `UPGRADE-GIT-4.3.29-RU.md`. Реальный API-вызов и сборка Docker должны быть проверены после установки с ключом пользователя.
