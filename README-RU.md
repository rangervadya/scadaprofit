# ScadaProfit 4.3.27

Обновление 4.3.27 собрано как накопительное поверх предоставленного проекта 4.3.23. Оно сохраняет улучшения 4.3.24: очередь загрузки схем домов, топологическую обработку, отдельный слой кандидатов на проверку, ручной CAD LPGCad R1 и экспорт SVG/DXF.

Исправлены авторизация Yandex Vision OCR для сервисного аккаунта (без лишнего заголовка x-folder-id) и порядок обработки: Yandex Vision OCR вызывается первым на всё изображение. Локальный Qwen3-VL запускается как резерв, только если Yandex отключён, завершился ошибкой или не вернул ни одной подписи. Это устраняет ожидание девяти медленных локальных OCR-запросов перед облачным распознаванием. Tesseract остаётся дополнительным OCR-источником. Мультимодальная Qwen3.6-35B-A3B предлагает маршруты труб. Локальные Qwen3-VL и Tesseract не удалены и продолжают работать. Облачный провайдер по умолчанию выключен; его можно отдельно настроить, протестировать и при необходимости удалить без затрагивания локальных движков.

Облачные маршруты проверяются по исходным пикселям и геометрии OpenCV; непроверенные подписи и сомнительные соединения остаются на ручной проверке. API-ключ хранится на сервере в закрытом файле внутри существующего тома данных ScadaProfit и не возвращается браузеру.

Обновление ограничено файлами из `UPDATE-MANIFEST-4.3.27.txt`. `vdgo/`, Compose, Nginx, PostgreSQL и тома не изменяются. Установка и тест Yandex описаны в `UPGRADE-GIT-4.3.27-RU.md`. Проверка реального API требует ключа и IAM-ролей пользователя; серверная Docker-сборка после обновления ещё должна быть выполнена.
