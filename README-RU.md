# CAD Reconstruction Engine 4.3.1

Локальная реконструкция фотографий инженерных схем в SVG/DXF. Обработка происходит в Docker на сервере пользователя с локальной Qwen/Ollama и OpenCV.

## Основные каналы
- OCR Qwen + Tesseract; дополнительный проход читает плотные рукописные блоки построчно.
- OpenCV LSD/Hough строит топологический граф и отбирает связные геометрические маршруты.
- Трассы Qwen проверяются по поддержке исходными пикселями и текстовым маскам; только подтверждённые трассы добавляются в `PIPE_MAIN`.
- Результаты OCR с низкой уверенностью не теряются: они экспортируются на замороженный слой `TEXT_REVIEW`.

## Слои DXF
`PIPE_MAIN`, `DETAIL_REVIEW`, `QWEN_REVIEW`, `VERIFIED_TEXT`, `TEXT_REVIEW`, `SHEET`, `NOTES`.

## Обновление
См. [UPDATE-RU.md](UPDATE-RU.md). Не удаляйте `.env` и не используйте `docker compose down -v`.

## Ограничения
Проверка синтетических схем не доказывает полную точность на любой рукописной фотографии. Все соединения, размеры и распознанные надписи нужно сверять с оригиналом перед техническим применением.
