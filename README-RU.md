# ScadaProfit CAD Reconstruction Engine 4.3.20

Версия 4.3.20 добавляет отдельный редактор **«Ручной CAD»** для аккуратного переноса рукописных схем трубопроводов в редактируемую векторную геометрию. В редакторе есть инструменты труб, ответвлений с явными узлами соединения, подписей, условных обозначений и размеров; проекты сохраняются на сервере, экспорт доступны в SVG и DXF на листе A4.

Это инструмент ручной векторизации, а не обещание автоматического распознавания рукописного чертежа без участия человека. Исходная фотография используется как подложка редактора и не попадает в чистовой экспорт. Соединения возникают только при явной привязке конца/начала новой трубы к существующей линии; обычное пересечение линий не превращается в узел автоматически. Результат всё равно необходимо проверить инженеру по исходному чертежу.

**VDGO не затрагивался:** файлы в `vdgo/`, VDGO backend/frontend, база данных, Docker-сервисы и тома не изменялись. Обновление добавляет отдельную страницу `/manual-cad.html` и отдельный API `/api/manual-cad/*` внутри основного CAD-приложения.

Установка: `UPGRADE-GIT-4.3.20-RU.md`. Сохраняйте `.env`, `.git` и Docker-том `cad_jobs`; не используйте `docker compose down -v`. Руководство: `MANUAL-CAD-USER-GUIDE-RU.md`.
