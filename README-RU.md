# ScadaProfit 4.3.31

В версии 4.3.31 исправлен разбор OCR-ответа MOSS-VL, который возвращает единственную область верхнеуровневым объектом с полями `text` и `bbox` вместо массива `annotations`. Версия 4.3.30 также поддерживала стандартные/альтернативные массивы текстовых областей. Парсер поддерживает стандартный массив `annotations`, распространённые варианты `texts`/`text_regions` и вложенные JSON-объекты `result`/`data`/`ocr`. Координаты берутся только из явно переданных рамок или полигонов; если геометрии текста нет или она выходит за пределы исходной фотографии, подпись не создаётся и остаётся резервный OCR Qwen/Tesseract.

MOSS Vision уже вернул 8 кандидатов труб на тестовом изображении, но это только результат распознавания модели: маршруты должны пройти локальную проверку по исходным пикселям и топологии, а спорные соединения — ручную проверку. Число «8 маршрутов» не является подтверждением корректности готовой схемы.

Локальный Ollama Qwen3-VL и Tesseract сохраняются. OpenRouter и MOSS остаются раздельными облачными провайдерами; при активном MOSS OpenRouter не вызывается. API-ключ MOSS хранится только на сервере.

Обновление затрагивает основной ScadaProfit и тесты/документацию. `vdgo/`, `compose.yaml`, Nginx, PostgreSQL и Docker volumes не изменяются. Реальный OCR-ответ MOSS и Docker-сборка 4.3.30 проверяются после установки обновления.
