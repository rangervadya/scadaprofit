# CAD Reconstruction Engine 4.3.3

Реконструкция рукописных схем трубопроводов в SVG/DXF: независимый OCR, геометрический граф OpenCV, семантические подсказки Qwen и раздельные слои проверки.

В 4.3.3 сомнительные Tesseract-рамки больше не вырезают геометрию автоматически; Qwen обрабатывает лист в сетке 3×3; подсказки соединений исключают самостыковки и endpoint-to-interior дубликаты.

См. `INSTALL-4.3.3-RU.md` и `CHANGELOG-RU.md`. Перед инженерным использованием проверяйте трассы, размеры и подписи по оригиналу.
