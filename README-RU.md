# CAD Reconstruction Engine 4.3.5

В 4.3.5 список возможных соединений строится по открытым концам как `line_structure`, так и `ambiguous` компонентов. Короткие подтверждённые штрихи длиной от 8 px больше не исключаются только по порогу 25 px. Кандидаты не объединяются автоматически: UI показывает расстояние, соосность, чернильную поддержку, OCR-перекрытие, конфликтующие альтернативы и уровень проверки. Пользователь вручную добавляет выбранный соединительный отрезок. Текстовые/аннотационные компоненты исключены.

Сохранены изменения 4.3.4: общий тайм-аут Python — 45 минут, потоковые журналы этапов, лимиты отдельных запросов Ollama без изменений.

Установка: `INSTALL-4.3.5-RU.md`. Перед инженерным использованием проверяйте трассы, узлы, пересечения, размеры и подписи по оригиналу.
