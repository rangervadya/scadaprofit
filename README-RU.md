# ScadaProfit 4.3.22 — LPGCad R1 и совместная работа с VDGO

Версия 4.3.22 добавляет профиль чистового инженерного листа **LPGCad R1** в существующий Manual CAD. Автоматический черновик из распознавания можно открыть в редакторе; исходная геометрия переносится без выдумывания новых труб и соединений, сомнительные элементы требуют проверки.

## Что добавлено

- Профиль оформления с шапкой заключения, заголовком «Схема», адресом объекта и подъездом, подзаголовком, подписями составителя и чертёжника, легендой и форматом листа A4/A3.
- Отдельный ввод нижних групп стояков: одна строка на группу, например `Ст-5: 67, 63, 59, 55, 51`. Название стояка и номера квартир берутся только из введённых оператором данных.
- Группы стояков выводятся в SVG и DXF как отдельная векторная область и DXF-слой `RISER_GROUPS`. Трассы основной сети, ответвления и стояки остаются на отдельных слоях.
- В настройках приложения, установочном скрипте и диагностике единый тег модели по умолчанию `qwen3-vl:4b-instruct`. Само наличие модели проверяется через `/api/health`; обновление не скачивает модель автоматически.

## Адресный архив и два приложения в одном комплекте

Функция «Улицы и дома» сохранена: существующая адресная библиотека и загрузка схем по домам остаются в ScadaProfit. В переданном архиве адресный справочник использует `address-library.json` в постоянном каталоге данных приложения; схема и доступы отдельной базы данных заказчика не предоставлены, поэтому подключение к ней в этом обновлении не создавалось.


Сохраняется существующая архитектура: **ScadaProfit** открывается по `/`, **VDGO** — по `/vdgo/`. Оба приложения остаются в одном Docker Compose-стеке с существующим gateway. Этот патч не удаляет и не заменяет `vdgo/`, VDGO frontend/backend, `compose.yaml`, Nginx, PostgreSQL или постоянные тома. Для обновления ScadaProfit перезапускается только сервис `app`.

## Ограничения и инженерная проверка

- Автоматическое распознавание Qwen/Tesseract по-прежнему не гарантирует полное восстановление всех труб, символов и соединений. Перед переносом в чистовой документ проверьте граф и OCR.
- Автоматически распознанные номера квартир не распределяются по стоякам, если нет подтверждённой связи. Нижние группы строятся из явно введённых строк `Название: номера`.
- Равномерная компоновка строк стояка — схематическое оформление, а не измерение высот этажей. Не используйте её как геодезические/монтажные размеры.
- SVG и DXF являются редактируемой векторной документацией, но выпуск схемы требует проверки специалистом по исходному чертежу и фактическому объекту.
- В этой среде выполнены 9 Node-тестов Manual CAD, 124 Python-теста и SVG-превью; Docker CLI, целевой сервер и Ollama/GPU здесь недоступны, поэтому `docker compose config`, Docker-сборка и реальный Qwen-прогон не выполнялись.
