# CAD Reconstruction Engine 4.3.2

Локальная реконструкция фотографий инженерных схем в SVG/DXF. Обработка происходит в Docker на сервере пользователя с локальной Qwen/Ollama и OpenCV.

## Основные каналы
- OCR Qwen + Tesseract; плотные нумерованные заметки определяются по исходным чернилам и отправляются в отдельный OCR-запрос для каждой строки. Если распознавание строки не удалось, её рамка всё равно остаётся в `TEXT_REVIEW` и исключает почерк из геометрии.
- OpenCV LSD/Hough строит топологический граф; короткие хорошо подтверждённые ответвления сохраняются, если они подключены к уже классифицированной трубопроводной компоненте.
- Малые разрывы между соосными участками соединяются только при наличии реальных чернильных пикселей внутри промежутка; расширенная маска концов не считается доказательством непрерывности.
- Трассы Qwen проверяются по поддержке исходными пикселями и текстовым маскам; только подтверждённые трассы добавляются в `PIPE_MAIN`.
- Низкоуверенные надписи экспортируются отдельно на `TEXT_REVIEW`.

## Слои DXF
`PIPE_MAIN`, `DETAIL_REVIEW`, `QWEN_REVIEW`, `VERIFIED_TEXT`, `TEXT_REVIEW`, `SHEET`, `NOTES`.

## Диагностика
В `graph.json` доступны `summary.text_block_rows_detected`, `summary.text_block_rows_returned`, `summary.text_block_rows_verified` и `ocr.qwen.block_diagnostics[].row_diagnostics`. Изображение `handwritten-text-blocks.png` показывает рамки блока и каждой строки.

## Обновление
См. [INSTALL-4.3.2-RU.md](INSTALL-4.3.2-RU.md). Не удаляйте `.env` и не используйте `docker compose down -v`. Сохраните `public/styles.css`.

## Ограничения
61 автоматический тест включает синтетическую трубопроводную топологию и тесты построчного OCR. Это не доказывает стопроцентную точность на любой рукописной фотографии; соединения, размеры и распознанные надписи нужно сверять с оригиналом перед техническим применением.
