# ScadaProfit 4.3.40 — линейная векторизация исходных чертежей

## Что изменено в 4.3.40

- Добавлена скелетизация исходных штрихов и экспорт в **открытые SVG path / DXF LWPOLYLINE**, а не в тысячи замкнутых контуров. Это устраняет эффект «точек» при просмотре тонкой схемы в CAD.
- В результате есть три режима: «Линии оригинала» (новый режим по умолчанию), «Контуры оригинала» и «CAD-реконструкция».
- SVG/DXF линейной векторизации содержат непрерывные открытые полилинии между концами и узлами; узлы ветвления сводятся к общему центру, чтобы лучи визуально сходились.
- Скелетизация реализована на NumPy без `scikit-image` и без `opencv-contrib`: Docker-зависимости и GPU-нагрузка не увеличиваются.
- Контурная факсимильная копия и структурный CAD-черновик оставлены отдельными режимами.

**Важное различие:** линейная векторизация превращает видимые штрихи оригинала в настоящие редактируемые открытые полилинии. Она не определяет автоматически, какой штрих является трубой, размерной линией, символом или текстом. Семантическую сеть труб по-прежнему формируют Qwen/OpenCV и проверяет специалист.

## Локальное распознавание и серверные ресурсы

Основной рабочий конвейер остаётся локальным: Qwen-VL через Ollama и Tesseract (`rus+eng`). Трассировка труб Qwen не блокируется неполным OCR. Параметры ограниченного запроса Qwen передаются только со стороны ScadaProfit. Контейнер Ollama и процессы других приложений не нужно останавливать или перенастраивать.

## VDGO

В этой версии изменены файлы ScadaProfit и отображение результатов. `vdgo/`, `compose.yaml`, gateway/Nginx, PostgreSQL, Docker volumes и `.env` не изменялись. На сервере обновляйте только `app`:

```bash
docker compose build app
docker compose up -d --no-deps app
```

Не выполняйте `docker compose down -v`, `docker compose up -d --force-recreate` и команды очистки Docker volumes для этого обновления.

## Проверки

Запуск локальных проверок:

```bash
npm run check
```

Добавлены тесты: крестовина экспортируется четырьмя открытыми полилиниями; одиночная точка не превращается в линию; Г-образная трасса остаётся полилинией; скелет остаётся односвязным. Реальный инференс Qwen на сервере пользователя из среды сборки недоступен. Векторная линейная копия сохраняет штрихи оригинала, но не является подтверждением инженерной топологии.
