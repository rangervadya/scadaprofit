# CAD Reconstruction Engine 4.3.4

Реконструкция рукописных схем трубопроводов в SVG/DXF: независимый OCR, геометрический граф OpenCV, семантические подсказки Qwen и раздельные слои проверки.

В 4.3.4 общий тайм-аут дочернего Python-процесса увеличен до 45 минут. Python запускается через `spawn`: этапы и номера фрагментов поступают в `docker compose logs -f app` по мере выполнения и сохраняются в `progress.log` внутри каталога задания. Лимиты отдельных запросов Ollama не менялись.

См. `INSTALL-4.3.4-RU.md` и `CHANGELOG-RU.md`. Перед инженерным использованием проверяйте трассы, размеры и подписи по оригиналу.
