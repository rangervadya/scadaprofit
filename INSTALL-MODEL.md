# Нужна ли модель Ollama?

Для основной OpenCV-векторизации — нет. Для отдельной лаборатории Qwen JSON в версии 2.6.0 — да. Векторная геометрия основного режима извлекается локально средствами OpenCV: цветные/контрастные пиксели → скелет штрихов → граф → SVG/DXF.

Ollama оставлен в Docker Compose только для совместимости с прежними установками и будущих экспериментов. Qwen не вызывается для рисования труб, поэтому пустой JSON от Qwen не может привести к пустому или выдуманному CAD-чертежу.

Наличие Ollama можно проверить:

```bash
docker compose exec ollama ollama list
```

Не удаляйте volume `ollama_data` при обновлении.

Лаборатория JSON использует Ollama API `http://ollama:11434/api/chat` и модель из `QWEN_MODEL` (по умолчанию `qwen3-vl:4b-instruct`). Проверить её можно в секции «Лаборатория Qwen JSON» на веб-странице.
