# Локальная Qwen3-VL для распознавания подписей

Основная геометрия по-прежнему извлекается OpenCV из пикселей. Qwen3-VL используется только для чтения рукописных букв, цифр, обозначений диаметров и размерных надписей; модель не создаёт и не удаляет линии труб.

Требуется Ollama версии 0.12.7 или новее (Qwen3-VL в Ollama использует этот минимум).

По умолчанию Docker Compose обращается к `http://ollama:11434/api/chat` и использует `qwen3-vl:4b`. Загрузите модель один раз:

```bash
docker compose exec ollama ollama pull qwen3-vl:4b
docker compose restart app
```

Для Ollama, запущенного непосредственно на хосте, используйте `compose.host-ollama.yaml`. При обычном локальном запуске Python по умолчанию обращается к `http://127.0.0.1:11434/api/chat`.

Проверить конфигурацию можно через `GET /api/health`: поле `qwenModel` показывает модель, а `ollamaConfigured` — задан ли адрес Ollama. Если Qwen недоступна, приложение продолжает анализ геометрии и использует Tesseract как запасной OCR.

Не удаляйте Docker volume `ollama_data` при обновлении: в нём хранятся скачанные модели.
