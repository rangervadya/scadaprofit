# Локальная Qwen3-VL для CAD-реконструкции

В версии 4.2.7 Qwen3-VL используется для двух отдельных задач:

1. **Семантическая трассировка:** модель должна вернуть осевые маршруты труб, точки поворотов и ответвления в JSON. Рукописные цифры, размеры, выноски, стрелки и символы не должны становиться трубопроводами. Эти маршруты используются как независимые подсказки на слое `QWEN_REVIEW`; основной `PIPE_MAIN` строится по отобранной геометрии OpenCV.
2. **OCR:** изображение делится на четыре перекрывающихся увеличенных фрагмента; модель возвращает текст и bbox. Распознанные подписи экспортируются как редактируемые CAD TEXT. Боксы средней уверенности также помогают исключить рукописные штрихи из линейных кандидатов.

Нужна Ollama 0.12.7 или новее и модель `qwen3-vl:4b-instruct` (более крупная модель может повысить качество, но требует больше ресурсов).

Для Docker Compose: загрузите модель один раз:

```bash
docker compose exec ollama ollama pull qwen3-vl:4b-instruct
docker compose restart app
```

Для Ollama на хосте используйте `compose.host-ollama.yaml`. При обычном локальном запуске Python по умолчанию обращается к `http://127.0.0.1:11434/api/chat`.

## Проверка перед анализом

Откройте `http://АДРЕС-СЕРВЕРА:3001/api/health`. В ответе теперь есть `ollama.reachable`, `ollama.modelInstalled`, фактический список установленных моделей и подсказка, что исправить.

Для Docker выполните из каталога проекта:

```bash
# Убедиться, что сервис Ollama запущен
docker compose up -d ollama

# Установить модель в том Ollama (обычно скачивается один раз)
docker compose exec ollama ollama pull qwen3-vl:4b-instruct

# Перезапустить обработчик после установки модели
docker compose restart app
```

Если Ollama установлена прямо на сервере, а не в Compose:

```bash
ollama list
ollama pull qwen3-vl:4b-instruct
curl http://127.0.0.1:11434/api/tags
```

Затем проверьте `compose.host-ollama.yaml` и адрес `OLLAMA_CHAT_URL`/`OLLAMA_TAGS_URL`.

## Настройки (ScadaProfit 4.3.24)

- `QWEN_MODEL` — модель Ollama, по умолчанию `qwen3-vl:4b-instruct`.
- `QWEN_OCR_TILE_GRID=3` — базовая сетка OCR. Для обычных снимков/сканов с длинной стороной до 1600 px и короткой до 1200 px движок автоматически использует 2×2 перекрывающихся фрагмента; более крупные листы остаются на настроенной сетке 3×3.
- `QWEN_OCR_UPSCALE=2.0` — увеличение OCR-фрагментов для чтения мелких цифр.
- `QWEN_OCR_TIMEOUT=240` — эффективный тайм-аут одного OCR-фрагмента в секундах. Старое значение Compose `180` автоматически повышается до 240.
- `QWEN_PIPE_TRACE_TIMEOUT=300` — эффективный тайм-аут фрагмента трассировки труб. Старое значение Compose `240` автоматически повышается до 300.
- `QWEN_TILE_RETRY_BUDGET=0` — старое значение `0` трактуется как одна ограниченная повторная попытка при временном тайм-ауте/ошибке Ollama. Для полного отключения укажи `QWEN_TILE_RETRY_BUDGET=off`; значение `1` также означает одну попытку.
- `QWEN_PIPE_MAX_IMAGE_EDGE=2048` — максимальная сторона изображения для задачи трассировки труб.
- `QWEN_PIPE_MIN_CONFIDENCE=35` — минимальная уверенность маршрута. Маршруты всё равно проходят отдельную проверку по исходным чернилам; неподтверждённые линии остаются на проверке.

Сетка 2×2 уменьшает число отдельных вызовов для обычного изображения с девяти до четырёх, но не отменяет контроль полноты: если одна плитка не прошла обработку, этап остаётся неполным, а успешные плитки сохраняются в checkpoint. При изменении эффективной сетки контрольные точки, созданные для старой 3×3 сетки, могут быть рассчитаны заново.

`GET /api/health` сообщает модель, настроенные и эффективные тайм-ауты, бюджет повторов и стратегию адаптивной сетки, а также наличие адреса Ollama. Если Ollama недоступна или маршруты не распознаны, `/api/health`, строка состояния и `graph.json → semanticTrace` показывают причину и действие. Отсутствующее поле `confidence` больше не обнуляет правильный маршрут: применяется пометка 60% и он остаётся на проверку. Поддерживаются как объекты маршрутов, так и обычные массивы координат. Приложение сохраняет геометрические кандидаты на замороженном слое `DETAIL_REVIEW`, но не выдаёт их за трубопроводы на основном листе. На лист выводится явное предупреждение.

Не удаляйте Docker volume `ollama_data` при обновлении: в нём хранятся скачанные модели.
