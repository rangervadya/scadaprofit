Лаборатория Qwen JSON

Сначала Qwen извлекает точки и связи из фотографии. Затем его JSON можно передать отдельному запросу для построения пути. Справа отображается геометрия, нарисованная напрямую из JSON браузером — без CAD-рендерера.
