ScadaProfit 4.3.41 — КОНТРОЛЬ КАЧЕСТВА CAD

Результат по умолчанию теперь показывает исходную фотографию, если CAD не прошёл проверку топологии, классификации символов и привязки размеров. Это исправляет неверное представление сырой скелетизации как готового чертежа.

Режимы «Все штрихи» и «Контуры штрихов» остаются диагностическими. Для неподтверждённого CAD-черновика чистовой экспорт SVG/DXF/PDF отключён. В диагностике JSON добавлен блок cadReadiness.

Для последнего результата критерии не пройдены: 406 открытых концов / 428 сегментов; 173 пересечения / 428; 0/11 классифицированных символов; 1/8 привязанных размеров.

VDGO, Ollama, PostgreSQL, Compose, Nginx, тома и другие приложения не изменялись.

Установка: git pull --ff-only; docker compose build app; docker compose up -d --no-deps app.
Подробнее: README-RU.md и CHANGELOG-4.3.41-RU.md.
