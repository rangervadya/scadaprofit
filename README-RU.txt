ScadaProfit 4.3.38 — локальный Qwen + Tesseract и CAD-workbench

Основные изменения:
- OCR: локальный Qwen3-VL/Ollama — основной распознаватель; Tesseract с rus+eng дополняет текстовые области.
- PIPE semantic trace: только локальный Qwen. MOSS и OpenRouter не участвуют в нормальной обработке, независимо от старых ключей/флагов.
- Повторная обработка сохранённой схемы использует тот же локальный режим.
- Панель /api/health показывает доступность Ollama, установленную модель и языки Tesseract.
- Улучшен CAD: вершины, перетаскивание целой ветки с сохранением стыков, ортогональный режим, zoom, дублирование Ctrl+D, типы символов и номерная выноска.
- Приложение VDGO оставлено в составе исходного проекта без изменений: его контейнеры, frontend/backend, gateway, PostgreSQL и Docker volumes сохранены.

Развёртывание:
- Существующий docker compose deployment оставлен без изменения.
- Убедитесь, что Ollama доступна из контейнера приложения через OLLAMA_CHAT_URL/OLLAMA_TAGS_URL и что модель QWEN_MODEL загружена.
- Tesseract должен содержать языки rus и eng.
- Пересоберите и перезапустите только сервис приложения по принятой у вас процедуре; VDGO и БД для обновления не пересоздавайте.

Проверки:
  npm run check

Внимание: распознавание сложной схемы и сопоставление с оригиналом требуют инженерной проверки. В этом пакете выполнены офлайн-тесты; Qwen на вашем серверном GPU здесь не запускался.
