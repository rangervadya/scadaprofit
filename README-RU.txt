ScadaProfit 4.3.40 — ЛИНЕЙНАЯ ВЕКТОРИЗАЦИЯ ИСХОДНЫХ ЧЕРТЕЖЕЙ

В версии 4.3.40 добавлены открытые SVG path и DXF LWPOLYLINE, полученные из скелета исходных штрихов. Результат по умолчанию — «Линии оригинала», а не замкнутые контуры. Оставлены варианты «Контуры оригинала» и «CAD-реконструкция».

Открытые полилинии сохраняют все видимые штрихи, включая текст и символы, поэтому они не равны автоматически распознанной сети труб. Подтвердите инженерные соединения и назначение линий перед использованием.

Для установки через Git: git pull --ff-only; docker compose build app; docker compose up -d --no-deps app. Не перезапускайте Ollama, VDGO, PostgreSQL и другие приложения.

Подробнее: README-RU.md, README-4.3.40-RU.txt и CHANGELOG-4.3.40-RU.md.
