ScadaProfit 4.3.39 — векторная копия оригинала + отдельная CAD-реконструкция

КЛЮЧЕВОЕ ИЗМЕНЕНИЕ
Теперь результат не зависит от того, успела ли Qwen распознать все плитки текста.

В каждой обработке формируются два отдельных результата:

1) reference-trace.svg / reference-trace.dxf
   Контурная векторная копия исходного изображения. Сохраняет расположение труб,
   символов, размеров, номеров, подписей и легенды. SVG содержит редактируемые
   контуры; DXF содержит редактируемые замкнутые полилинии слоя REFERENCE_TRACE.

2) cad-draft.svg / cad-draft.dxf
   Структурная CAD-реконструкция: отрезки, узлы, маршруты, OCR-текст и кандидаты
   оборудования. При неполном распознавании это черновик и требует проверки.

В интерфейсе результата есть переключатель:
- «Копия оригинала»
- «CAD-реконструкция»

Ограничение: reference-trace — контурная векторная факсимильная копия, близкая к внешнему виду исходника,
а не семантическая сеть труб. DXF-контуры описывают границы чернильных штрихов,
не осевые линии труб. Соединения, размеры и обозначения проверяются инженером.

QWEN / TESSERACT
- Qwen OCR и Qwen PIPE выполняются независимо друг от друга.
- Тайм-аут OCR больше не отменяет трассировку труб.
- Tesseract рус/англ остаётся независимым источником распознанных надписей.
- Контекст Qwen по умолчанию 4096, плитки 2×2, timeout 105 секунд, max image edge
  1280, output 1024 токена, num_batch 96, num_threads 2.
- Модель удерживается примерно 30 секунд после последнего запроса, чтобы затем
  освободить видеопамять для других процессов.
- Параметры задаются приложением ScadaProfit в запросах к Ollama. Контейнер
  Ollama и остальные приложения не требуется пересоздавать, останавливать или менять.

ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB
На рабочем компьютере перенесите изменённые файлы в свой Git checkout и выполните:
  git status
  git diff --check
  npm run check
  git add -A
  git status
  git commit -m "ScadaProfit 4.3.39 source trace and independent Qwen PIPE"
  git push origin HEAD

На сервере:
  cd /opt/scadaprofit
  git status
  git pull --ff-only
  docker compose config --quiet
  docker compose build app
  docker compose up -d --no-deps app
  docker compose ps
  docker compose logs --tail=100 app

Контейнер Ollama не требуется пересоздавать или перезапускать: параметры
`num_ctx`, `num_batch`, `num_thread` и `keep_alive` ScadaProfit передаёт явно
в каждом локальном запросе. Обновляется только сервис `app`.
Не выполняйте `docker compose down -v`, `docker volume prune` или `docker system prune`.

VDGO, PostgreSQL, gateway/Nginx и volumes в этой версии не изменялись.
