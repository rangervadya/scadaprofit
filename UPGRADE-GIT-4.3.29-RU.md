# ScadaProfit 4.3.29 — MOSS-VL

Это обновление добавляет MOSS-VL как основной облачный мультимодальный провайдер. Локальные Qwen3-VL и Tesseract сохраняются. OpenRouter остаётся дополнительной настройкой, но при включённом MOSS не вызывается.

## Важно: границы изменений

Обновление касается только основного приложения ScadaProfit. Оно не меняет `vdgo/`, `compose.yaml`, Nginx, PostgreSQL, базу данных или Docker volumes. Ключ MOSS не входит в архив и не должен попадать в Git.

## Применение на Mac

1. Убедись, что локальный проект соответствует ScadaProfit 4.3.28 и нет незакоммиченных личных изменений.
2. Примени PATCH или распакуй ZIP поверх корня проекта.
3. Выполни `npm run check`.
4. Проверь `git status --short`: в изменениях не должно быть `vdgo/`, `compose.yaml` или `nginx-unified.conf`.
5. Отправь изменения в `main` обычным commit/push.

## Обновление сервера

На сервере: обновляем только сервис `app`. Не запускай `docker compose down`, не пересоздавай gateway, VDGO или PostgreSQL.

```bash
cd /opt/scadaprofit
git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
```

Только если сборка завершилась успешно:

```bash
sudo docker compose up -d --no-deps app
sudo docker compose ps
curl -sS http://127.0.0.1:3001/api/health
```

Ожидаем `version: 4.3.29` и объект `mossAI` в health.

## Подключение MOSS

1. Открой ScadaProfit и обнови страницу жёстко (`Cmd+Shift+R`).
2. В блоке «Облачный AI · MOSS-VL» вставь API-ключ MOSS.
3. Включи MOSS, OCR и трассировку труб; модель `moss-vl-1.0` фиксирована в приложении.
4. Нажми «Сохранить настройки». Ключ хранится на сервере в `.private/moss-ai-settings.json` с правами `0600`; браузер его обратно не получает.
5. Открой фотографию тестовой схемы и нажми «Проверить открытую схему». Это два мультимодальных запроса: OCR и трассировка. Результат теста не меняет проект.

MOSS API временно помечает `moss-vl-1.0` как бесплатную модель с нулевой стоимостью в кредитах. Условия бесплатного использования могут измениться. Для каждого вызова ScadaProfit загружает исходное изображение через `/v1/files`, использует `file_id` в `/v1/responses` и пытается удалить API-файл после завершения запроса. Используй для теста обезличенную копию схемы без адресов, ФИО, телефонов и иных персональных/конфиденциальных данных.

## Диагностика

Если тест не прошёл, пришли текст статуса MOSS и серверный журнал `sudo docker compose logs --since=10m --tail=120 app`. Не присылай API-ключ. Не повторяй тест много раз, чтобы не тратить бесплатный лимит.
