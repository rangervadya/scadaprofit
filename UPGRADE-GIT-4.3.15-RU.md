# Обновление до 4.3.15 — общий эталон оформления

## Что добавлено

- В левой панели появился раскрываемый раздел «Шаблон оформления».
- Можно загрузить один общий эталон в формате PDF, SVG, DXF, PNG, JPG, WEBP или TIFF (до 30 МБ).
- Новый файл заменяет предыдущий эталон; текущий можно скачать или удалить.
- Шаблон хранится в `DATA_DIR/.private/template` рядом с адресной библиотекой, внутри постоянного Docker-тома `cad_jobs`.
- Файл шаблона не попадает в папку дома, не считается входящей схемой и не запускает Qwen/OCR.

## Важное ограничение

Эта версия добавляет загрузку и постоянное хранение эталона. Она **не извлекает автоматически** из загруженного файла правила линий, шрифтов и размеров и пока не применяет их к SVG/DXF-экспорту. Для этого после загрузки нужно посмотреть сам эталон и отдельно сопоставить его слои/стили с генератором. Нельзя обещать совпадение результата с шаблоном до этой настройки.

В проекте пока нет учётных записей и ролей: любой человек, имеющий доступ к приложению, может заменить или удалить общий шаблон. Не публикуйте приложение в открытый интернет без авторизации.

## Файлы для GitHub

Заменить в ветке `main`, сохранив пути:

- `server.js`
- `package.json`
- `public/index.html`
- `public/app.js`
- `public/styles.css`

Затем сделать Commit changes. ZIP целиком в репозиторий не загружать.

## Обновление сервера

```bash
cd /opt/scadaprofit
git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps app
sudo docker compose ps
curl -sS http://127.0.0.1:3001/api/health
```

Ожидаемая версия API: `4.3.15`. Ollama не перезапускается. Не выполнять `docker compose down -v` и не удалять том `cad_jobs`.

## Проверка

1. Открыть «Шаблон оформления» в левой панели.
2. Загрузить эталон, например PDF или DXF.
3. Убедиться, что имя файла и ссылка «Скачать» появились.
4. Пересобрать контейнер `app` (без удаления томов) и проверить, что эталон всё ещё отображается.
5. Убедиться, что обычная отправка фото в папку дома по-прежнему работает отдельно.
