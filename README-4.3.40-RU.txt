ScadaProfit 4.3.40 — ЛИНИИ ОРИГИНАЛА И ОТКРЫТЫЕ CAD-ПОЛИЛИНИИ

Основное исправление: вместо замкнутых пиксельных контуров приложение теперь может экспортировать одно-пиксельный скелет исходных штрихов как открытые SVG path и DXF LWPOLYLINE. Это устраняет эффект отдельных точек при просмотре тонкой схемы в CAD.

В результате доступны три режима:
1) Линии оригинала — открытые линейные полилинии (режим по умолчанию).
2) Контуры оригинала — контурная факсимильная векторизация.
3) CAD-реконструкция — структурный черновик с кандидатами геометрии, OCR и Qwen.

Открытые полилинии повторяют все видимые штрихи, а не только газовые трубы. Текст, символы, размеры и выноски также векторизуются как линии. Это не подтверждение инженерной топологии; специалист должен проверить назначение линий и соединения.

Алгоритм использует NumPy без новых Python-зависимостей и не требует GPU. Другое приложение, Python-процесс, Ollama, VDGO и PostgreSQL не нужно останавливать или перенастраивать.

Установка через ваш обычный Git workflow:
  git pull --ff-only
  docker compose build app
  docker compose up -d --no-deps app

Не выполняйте docker compose down -v, --force-recreate и docker volume prune.

Проверки:
  npm run check
