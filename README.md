# CAD Reconstruction Engine 4.2.1

Локальный инструмент для преобразования фотографий рукописных инженерных схем в редактируемую векторную геометрию. OpenCV извлекает линии и узлы; Qwen3-VL через Ollama и Tesseract распознают подписи независимо от геометрии.

Основная документация, установка и обновление: [`README-RU.md`](README-RU.md), [`INSTALL-MODEL.md`](INSTALL-MODEL.md), [`UPDATE-RU.md`](UPDATE-RU.md).
