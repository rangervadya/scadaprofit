# CAD Sketch Converter Offline 2.4 (Docker)

Локальное приложение для анализа рукописных технических схем на Ubuntu. Qwen2.5-VL-3B извлекает граф схемы в структурированный JSON через Ollama Structured Outputs; сервер обрабатывает перекрывающиеся фрагменты изображения, объединяет геометрию, проверяет простые признаки качества и строит PNG/SVG/DXF. OpenCV и Tesseract выполняются локально. После первой загрузки Docker-образа и модели интернет для обработки не нужен.

> Важно: это экспериментальная реконструкция, а не инженерная CAD-система. JSON Schema гарантирует форму ответа, не истинность топологии. Проверяйте все соединения, размеры и подписи вручную.

## Базовые возможности

- Вместо свободного текста для CAD-режима отправляется JSON Schema (`format` в API Ollama).
- Модель возвращает `nodes` и `connections`, а не произвольные `routes`; конвертер строит сегменты из связей узлов.
- Плотные/большие изображения разбиваются на скользящую сетку перекрывающихся фрагментов. Координаты преобразуются обратно в систему исходного изображения; дубликаты маршрутов удаляются, близкие концы стыкуются.
- Система проверяет количество соединений, разнообразие координат и направлений. При явно схлопнувшейся геометрии она отказывает, а не выдаёт пустую линию.
- Отдельный `model-init` сервис сам скачивает `qwen2.5vl:3b` в постоянный Docker volume, если модели там нет. Это исправляет частый HTTP 404 «model not found» внутри свежего контейнера.
- Координаты нормализованы по обеим осям 0..1000; исходное отношение сторон сохраняется.

## Установка/обновление в существующем `/opt/scadaprofit`

Сначала сделайте резервную копию проекта. Из каталога проекта выполните `docker compose down` **без `-v`**: это сохраняет существующий том модели. Затем распакуйте архив в отдельный временный каталог и скопируйте файлы новой версии в каталог проекта, сохраняя локальный `.env`:

```bash
cd /opt/scadaprofit
docker compose down
mkdir -p /tmp/cad-sc-2.4
unzip -o cad-sketch-converter-docker-2.4.zip -d /tmp/cad-sc-2.4
cp -a /tmp/cad-sc-2.4/cad-sketch-converter-docker-2.4/. /opt/scadaprofit/
```

Проверьте `.env`. Он может содержать:

```dotenv
WEB_PORT=3001
QWEN_MODEL=qwen2.5vl:3b
```

Затем соберите и запустите:

```bash
cd /opt/scadaprofit
docker compose up -d --build
```

Compose дождётся Ollama и сам проверит/загрузит модель в Docker-volume. При первом запуске в новом volume потребуются интернет и около 3.2 ГБ загрузки; в существующем volume модель повторно скачиваться не должна.

Проверка:

```bash
docker compose ps
docker compose exec ollama ollama list
curl -s http://127.0.0.1:3001/api/health | python3 -m json.tool
curl -I http://127.0.0.1:3001/
docker compose logs --tail=100 app
```

Откройте `http://IP_СЕРВЕРА:3001` из браузера в доступной локальной сети. Чтобы узнать IP, выполните `hostname -I`.

## Требования

- Ubuntu Linux, Docker Engine и Compose plugin.
- NVIDIA Container Toolkit для GPU passthrough (проверьте `docker run --rm --gpus all ubuntu nvidia-smi`).
- GTX 1060 6 ГБ работает на нижней границе VRAM; держите один параллельный запрос. Отключите/остановите другие модели, пока обрабатывается схема.
- 16 ГБ RAM и свободное дисковое пространство; исходные фотографии до 15 МБ.

Если GPU passthrough не работает, см. https://github.com/ollama/ollama/blob/main/docs/docker.mdx. Перезапуск Docker может прервать другие контейнеры, например n8n.

## Диагностика

### Ollama HTTP 404

Обычно модель отсутствует в том Ollama, к которому подключено приложение. Проверьте `docker compose exec ollama ollama list`. Compose 2.4 сам делает pull при запуске. Вручную можно выполнить:

```bash
docker compose exec ollama ollama pull qwen2.5vl:3b
docker compose restart app
```

### Модель вернула слишком мало соединений

Логи покажут, сколько фрагментов проанализировано и почему отклонён результат:

```bash
docker compose logs --tail=150 app
```

Попробуйте более прямой снимок, высокое разрешение или крупные фрагменты исходника. Увеличение числа токенов/повторных попыток не гарантирует понимания геометрии.

### Безопасность

Приложение не имеет авторизации. Держите его в доверенной локальной сети и не публикуйте порт в интернете без дополнительной защиты.


## Версия 2.4 — исправления точности

- Расширен промпт: модель должна выдавать граф узлов и соединений, а не просто перечень линий. Повороты помещаются в промежуточные points, а соединения должны ссылаться на существующие node id.
- JSON Schema ограничивает координаты диапазоном 0..1000. Код отбрасывает выходящие за пределы точки, чтобы не прижимать ошибочные значения к краям кадра.
- Рендерер обрабатывает до 400 соединений (вместо 32) и не наносит служебные ID сегментов как подписи.
- Это не гарантирует точность Qwen2.5-VL-3B: проверяйте итоговую геометрию и размеры по оригиналу.
