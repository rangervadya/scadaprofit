# Two Mask Lab 3.4.0

Локальная лаборатория OpenCV + Tesseract для разделения изображения на маску текста и маску линий. В версии 3.4 добавлен freehand lasso: обведи рукопись по контуру, удали её из векторного слоя и при необходимости добавь проверенную печатную подпись.

См. `UPDATE-RU.md` для обновления на Ubuntu.
