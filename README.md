# CAD Sketch Converter Offline 2.3 (Docker)

Локальное приложение для распознавания рукописных технических схем на Ubuntu. Qwen2.5-VL-3B через Ollama Structured Outputs распознаёт **символы и подписи** (клапаны, насосы, клеммы, размеры, текст), а не топологию. Исходное изображение вставляется в SVG/PNG как полупрозрачный фон, чтобы инженер мог сравнить распознанные элементы с чертежом. OpenCV и Tesseract работают локально. После первой загрузки Docker-образа и модели интернет для обработки не нужен.

> **Важно:** модель определяет, *что* на схеме изображено, но не определяет, *какие элементы соединены*. Топологию и соединения нужно задавать вручную. Это вспомогательный инструмент, а не инженерная CAD-система.

## Что изменено в 2.3

- **Путь 3 — распознавание, а не реконструкция.** Модель больше не пытается восстановить топологию (узлы и соединения). Она возвращает только `symbols`, `labels`, `dimensions`, `legend`, `uncertainties`. Ранее попытки модели самой определять соединения приводили к разъединённым и искажённым сетям линий.
- **Исходное изображение как фон.** `cad_renderer.py` вставляет исходный скан в SVG/PNG с прозрачностью, чтобы распознанные символы можно было сверить с чертежом.
- **Перекрывающиеся фрагменты** генерируются скользящим окном с шагом ~62% от размера фрагмента, что гарантирует покрытие центральных областей широких чертежей (раньше было только 4 угла).
- **Координаты нормализованы по обеим осям 0..1000; исходное отношение сторон сохраняется** и ограничивается диапазоном 0.5–2.2, чтобы схема не сжималась в полоску.
- Отдельный `model-init` сервис сам скачивает `qwen2.5vl:3b` в постоянный Docker volume, если модели там нет. Это исправляет частый HTTP 404 «model not found» внутри свежего контейнера.

## Установка/обновление в существующем `/opt/scadaprofit`

Сначала сделайте резервную копию проекта. Из каталога проекта выполните `docker compose down` **без `-v`**: это сохраняет существующий том модели. Затем распакуйте архив в отдельный временный каталог и скопируйте файлы новой версии в каталог проекта, сохраняя локальный `.env`:

```bash
cd /opt/scadaprofit
docker compose down
mkdir -p /tmp/cad-sc-2.3
unzip -o cad-sketch-converter-docker-2.3.zip -d /tmp/cad-sc-2.3
cp -a /tmp/cad-sc-2.3/cad-sketch-converter-docker-2.3/. /opt/scadaprofit/
```

Проверьте `.env`. Он может содержать:

```dotenv
WEB_PORT=3001
QWEN_MODEL=qwen2.5vl:3b
```

Затем соберите и запустите:

```bash
cd /opt/scadaprofit
docker compose up -d --build
```

Compose дождётся Ollama и сам проверит/загрузит модель в Docker-volume. При первом запуске в новом volume потребуются интернет и около 3.2 ГБ загрузки; в существующем volume модель повторно скачиваться не должна.

Проверка:

```bash
docker compose ps
docker compose exec ollama ollama list
curl -s http://127.0.0.1:3001/api/health | python3 -m json.tool
curl -I http://127.0.0.1:3001/
docker compose logs --tail=100 app
```

Откройте `http://IP_СЕРВЕРА:3001` из браузера в доступной локальной сети. Чтобы узнать IP, выполните `hostname -I`.

## Требования

- Ubuntu Linux, Docker Engine и Compose plugin.
- NVIDIA Container Toolkit для GPU passthrough (проверьте `docker run --rm --gpus all ubuntu nvidia-smi`).
- GTX 1060 6 ГБ работает на нижней границе VRAM; держите один параллельный запрос. Отключите/остановите другие модели, пока обрабатывается схема.
- 16 ГБ RAM и свободное дисковое пространство; исходные фотографии до 15 МБ.

Если GPU passthrough не работает, см. https://github.com/ollama/ollama/blob/main/docs/docker.mdx. Перезапуск Docker может прервать другие контейнеры, например n8n.

## Диагностика

### Ollama HTTP 404

Обычно модель отсутствует в том Ollama, к которому подключено приложение. Проверьте `docker compose exec ollama ollama list`. Compose 2.3 сам делает pull при запуске. Вручную можно выполнить:

```bash
docker compose exec ollama ollama pull qwen2.5vl:3b
docker compose restart app
```

### Модель вернула слишком мало соединений

Логи покажут, сколько фрагментов проанализировано и почему отклонён результат:

```bash
docker compose logs --tail=150 app
```

Попробуйте более прямой снимок, высокое разрешение или крупные фрагменты исходника. Увеличение числа токенов/повторных попыток не гарантирует понимания геометрии.

### Безопасность

Приложение не имеет авторизации. Держите его в доверенной локальной сети и не публикуйте порт в интернете без дополнительной защиты.
