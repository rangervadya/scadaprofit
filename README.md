# CAD Reconstruction Engine 4.2.6

Локальный инструмент для преобразования рукописных инженерных схем в предварительные CAD-маршруты. Qwen3-VL через Ollama отдельно распознаёт текст и определяет осевые маршруты труб; OpenCV LSD/Hough сохраняет все найденные пиксельные отрезки как кандидаты для проверки, а не как подтверждённую трубную геометрию.

Основная документация, установка и обновление: [`README-RU.md`](README-RU.md), [`INSTALL-MODEL.md`](INSTALL-MODEL.md), [`UPDATE-RU.md`](UPDATE-RU.md).
