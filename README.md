# Two Mask Lab 3.0.0 — разделение текста и линий

Эта версия намеренно **не использует Qwen для геометрии**. Цель текущего эксперимента — проверить, можно ли на исходной фотографии достаточно хорошо отделить рукописные подписи и цифры от оставшихся штрихов трубопроводной схемы.

## Что делает приложение

1. Браузер отправляет оригинальный JPG/PNG/WEBP на локальный сервер.
2. OpenCV строит общую маску чернил. Режим `auto` определяет доминирующий цвет ручки; отдельно доступны `blue` и `dark`.
3. Tesseract OCR (`eng+rus`, `--psm 11`) ищет текстовые области и возвращает прямоугольники найденных слов.
4. **Маска текста** — чернильные пиксели внутри прямоугольников OCR с настраиваемым отступом.
5. **Маска линий** — все остальные чернильные пиксели вне областей OCR.
6. Приложение показывает оригинал и обе маски рядом, выводит число пикселей/областей OCR и позволяет скачать маски PNG и JSON-отчёт.

Маски — строгая непересекающаяся разбивка найденных чернил. На текущем этапе приложение не скелетизирует линии, не строит граф, не ищет соединения и не запускает Qwen.

## Важные ограничения

- Tesseract может не распознать рукописные цифры или надписи. Они останутся в маске линий.
- Если OCR-прямоугольник попадает на часть трубы, этот участок окажется в маске текста.
- Длинная размерная линия или стрелка, которую OCR не классифицировал как текст, останется в маске линий.
- В режиме `auto` выбирается доминирующий цвет чернил. Для синей ручки можно принудительно включить `blue`; для чёрной ручки/карандаша — `dark`.
- Это диагностический этап сегментации, не готовая CAD-реконструкция.

## Установка

Требования: Docker Engine и Docker Compose plugin. NVIDIA/Ollama для этой версии не нужны. Старый сервис Ollama и его volume оставлены в `compose.yaml` ради совместимости со старой установкой, но приложение к Ollama не обращается.

### Обновление существующей установки `/opt/scadaprofit`

Перед обновлением сделай резервную копию. Не удаляй Docker volume.

На Mac:

```bash
scp ~/Downloads/cad-sketch-converter-two-mask-3.0.zip \
  tech@192.168.1.99:/home/tech/
```

На сервере:

```bash
cd /opt/scadaprofit

tar -czf /root/scadaprofit-backup-$(date +%F-%H%M).tar.gz .

rm -rf /tmp/cad-two-mask-3.0
mkdir -p /tmp/cad-two-mask-3.0
unzip -oq /home/tech/cad-sketch-converter-two-mask-3.0.zip -d /tmp/cad-two-mask-3.0
cp -a /tmp/cad-two-mask-3.0/cad-sketch-converter-docker-3.0/. /opt/scadaprofit/

cd /opt/scadaprofit
docker compose config --quiet
docker compose build --no-cache app
docker compose up -d --force-recreate app
```

Команды обновляют только `app`. Сервис `ollama` и его volume не удаляются и не пересоздаются. **Не выполняй `docker compose down -v`.** Файл `.env` не включён в ZIP и остаётся на месте.

### Проверка

```bash
docker compose exec app node -p "require('./package.json').version"
curl -s http://127.0.0.1:3001/api/health | python3 -m json.tool
```

Ожидается версия `3.0.0`, режим `two-mask-lab`, процессор `OpenCV ink segmentation + Tesseract OCR boxes`, `qwenUsed: false`.

Открой `http://192.168.1.99:3001`, загрузи оригинальное фото, нажми **«Построить две маски»**. Начни с режима `Авто`, OCR confidence `15` и отступа `3 px`.

## Настройки

- **Тип чернил:** `auto`, `blue`, `dark`.
- **Уверенность OCR:** уменьшение порога помещает больше областей в текстовую маску, но повышает риск ошибочной классификации.
- **Расширение области текста:** увеличивает OCR-прямоугольники перед вырезанием текста из общей маски чернил.

## API

`GET /api/health` — состояние локального обработчика.

`POST /api/masks` — multipart поля:
- `image`: исходный файл;
- `mode`: `auto`, `blue` или `dark`;
- `minConfidence`: порог OCR от 0 до 90;
- `padding`: отступ от 0 до 24 пикселей.

Ответ включает PNG в base64 (`inkPngBase64`, `textPngBase64`, `linesPngBase64`, `overlayPngBase64`), OCR-боксы, статистику и предупреждения.
