# Two Mask Lab 3.3.0 — Clean Labels

Офлайн-лаборатория для разбиения фотографии схемы на две маски, скелетной векторизации штрихов и ручной замены рукописных подписей аккуратным печатным текстом в SVG.

## Важное отличие

Tesseract не всегда правильно читает рукописные цифры и буквы. Поэтому OCR-текст **не выводится печатным текстом автоматически**. В редакторе каждая OCR-область имеет две независимые операции:

1. **Убрать рукопись** — вырезает её исходные пиксели из слоя линий.
2. **Печатать** — добавляет содержимое текстового поля как ровную SVG-надпись. Включай только после проверки и исправления.

Для фрагментов, которые OCR пропустил, выбери «Выделить надпись на фото» и обведи её мышью. Область появится в редакторе. Введи точный текст (или оставь пусто, чтобы удалить почерк без замены), затем нажми «Применить подписи». OCR повторно не запускается — используются сохранённые координаты и ручные правки.

У каждой подписи показывается миниатюра исходного фрагмента, координаты, уверенность OCR и угол поворота печатного текста.

## Что остаётся исходным

- Фотография не изменяется.
- Бинарные PNG-маски остаются доступны в исходном разрешении.
- SVG геометрии строится отдельно из маски линий.
- Чистый SVG объединяет SVG-геометрию и только проверенные печатные подписи.
- Ollama/Qwen не вызывается. Всё выполняется локально через OpenCV и Tesseract.
