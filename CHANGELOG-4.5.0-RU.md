# ScadaProfit 4.5.0 — изменения рабочего процесса

## Эскиз и обработка
- Слесарь отправляет только изображение ручного эскиза, без фотографий объекта.
- После ручных отметок «начал обход», «прошёл дом», «пришёл в офис» эскиз уходит в штатную автоматическую CAD-очередь.
- Для каждой схемы создаётся CAD-job, связанный с конкретными улицей, домом, заданием и отчётом.

## Приёмка и заключение
- В меню приёмщика появляются уведомления с улицей, домом, автором и временем отправки.
- После открытия уведомление помечается просмотренным.
- Карточка уведомления содержит ручной эскиз, предпросмотр векторного результата CAD и переход в CAD-редактор.
- Кнопка переноса добавляет схему в раздел «Заключение», где отображаются SVG/DXF и предпросмотр.

## Аккаунты и безопасность
- Руководитель может создавать аккаунты слесарей и приёмщиков.
- Логин генерируется уникально из имени, пароль генерируется случайным образом и выводится создателю один раз.
- Вход проверяет конкретный логин и пароль через scrypt-хеш; выбора аккаунта вместо аутентификации нет.
- Оставлен лимит в два активных аккаунта руководителя.

## Геолокация
- GPS-функции и API передачи координат удалены из рабочего интерфейса.
- Старые GPS-массивы из сохранённого рабочего пространства очищаются при запуске обновлённой версии.
- Руководителям доступна только ручная событийная лента отметок этапов работы.

## Проверки
- Добавлены тесты реальной функции проверки учётных данных.
- Добавлены контрактные проверки интерфейса/серверных маршрутов для ручного трекера, отсутствия GPS и потока CAD → уведомление → заключение.
