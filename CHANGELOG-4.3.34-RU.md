# ScadaProfit 4.3.34 — исправление лимита MOSS Vision

- Исправлен параметр `max_output_tokens` в запросе MOSS Vision: теперь он равен 8192 и соответствует верхнему пределу API.
- Это устраняет HTTP 400 `max_output_tokens must be between 1 and 8192`, который блокировал Vision до начала распознавания труб.
- Разбор форматов маршрутов и проверка геометрии из 4.3.33 сохранены без изменений.
- Это исправление не гарантирует, что MOSS найдёт маршруты: результат Vision необходимо проверить на исходной схеме.

Изменены: `moss_ai.py`, `tests/test_moss_ai.py`, `package.json`.
Внешние сервисы, VDGO, `compose.yaml`, Nginx и Docker volumes не изменяются.
