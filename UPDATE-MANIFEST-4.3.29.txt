Provider behavior:
- MOSS-VL is the primary cloud provider when enabled.
- MOSS uses the official Files + Responses API workflow. Uploaded image files are sent by file_id and a deletion request is issued after each inference.
- On MOSS errors/empty OCR/routes, local Ollama Qwen3-VL remains fallback.
- Tesseract remains supplementary OCR.
- OpenRouter code/settings are retained as an optional provider but bypassed when MOSS is active (the current server's OpenRouter requests returned Cloudflare 403).
- MOSS API key is stored privately in the app's existing data directory and never returned to the browser or committed to Git.

Not modified: vdgo/, compose.yaml, nginx-unified.conf, PostgreSQL configuration/data/volumes, and Docker volumes.
