ScadaProfit 4.3.45 — автотрасса по эскизу слесаря

Новый инструмент «Автотрасса» в CAD позволяет пошагово указать ход одной трубы по синей или тёмной ручке. Отметьте начало, конец каждого прямого участка и точки поворотов. Между ними алгоритм ищет штрихи в ограниченном коридоре. Синий пунктир — только предпросмотр. Нажмите «Применить маршрут» после проверки.

Можно привязывать начало, конец и промежуточные точки к подтверждённым CAD-трубам; создаются явные узлы. Оранжевые кандидаты остаются непроверенными и не используются для привязки или чистового экспорта.

Это помощник ручной трассировки, а не распознавание смысла изображения. Не используйте результат как техническое заключение без проверки специалистом.

Развёртывание через Git: git push, затем на сервере git pull --ff-only; docker compose build app; docker compose up -d --no-deps app. Не требуется перезапускать Ollama/VDGO или другие приложения.
