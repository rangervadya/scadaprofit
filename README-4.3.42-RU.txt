ScadaProfit 4.3.42

Qwen PIPE теперь проверяет координаты строго по размерам изображения, реально переданного Ollama. Маршрут с точкой за пределами фрагмента отклоняется целиком; координаты не обрезаются до границ исходного листа. Это предотвращает фальшивые линии от ошибочных ответов вроде y=4800 для фрагмента высотой 480 px.

Подпись PIPE checkpoint обновлена: старые ответы с прежней логикой проверки не переиспользуются. Диагностика включает размеры sent_image, количество отклонённых маршрутов и примеры неверных координат.

Автоматический OCR-поворот на 180 градусов требует более сильного относительного перевеса 35%. Порог настраивается OSD_FALLBACK_180_MIN_MARGIN.

Обновление через Git: git add/commit/push; на сервере git pull --ff-only, docker compose build app, docker compose up -d --no-deps app.

VDGO, другие приложения, Ollama service, PostgreSQL, Nginx, Compose и volumes не изменяются.
