> Устаревшая инструкция для версии 4.4.0. Для версии 4.5.0 используй `WORKFORCE-QUICKSTART-4.5.0-RU.md`: в актуальном процессе нет GPS и фотоотчётов, а учётные записи создаются также руководителями.

# Быстрый запуск рабочей системы ScadaProfit 4.4.0

## 1. Запуск обновлённого приложения

Из каталога проекта:

```bash
docker compose build app
docker compose up -d --no-deps app
docker compose restart gateway
```

Если это первое развёртывание всего проекта, используй обычную команду:

```bash
docker compose up -d --build
```

Данные аккаунтов и заданий сохраняются в named volume `cad_jobs`; не удаляй его при обновлении.

## 2. Первоначальный аккаунт

1. Открой адрес приложения в браузере.
2. На экране первого запуска создай аккаунт разработчика: имя, уникальный логин и пароль от 10 символов.
3. Первый аккаунт получает роль **Разработчик**. Создать его повторно после завершения настройки нельзя.

## 3. Создание сотрудников

В панели разработчика открой **«Аккаунты и тесты»** и создай личные записи:

- двух пользователей с ролью **Руководитель**;
- одного или нескольких **Приёмщиков**;
- отдельную запись для каждого **Слесаря**.

У каждого пользователя должен быть собственный логин и пароль. Руководителей одновременно может быть не больше двух. Временные пароли передай сотрудникам по защищённому каналу; при необходимости разработчик может задать новый пароль в карточке аккаунта.

Логин: от 3 до 48 символов — латиница, цифры, точка, дефис или подчёркивание. Пароль: от 10 до 200 символов.

## 4. Ежедневный процесс

**Руководитель:** открой **«План работ»**, укажи название, улицу, дом, дату, исполнителя и инструкции, затем назначь выезд. В **«Контроль команды»** видны задания, статусы и разрешённые GPS-точки слесарей.

**Слесарь:** войди под личным аккаунтом. На экране **«Мои задания»** открой назначенный адрес, отметь начало работ и при необходимости включи геопозицию. После выезда прикрепи фотографии объекта и ручной эскиз (JPG/PNG/WEBP/TIFF либо PDF) и отправь отчёт.

**Приёмщик:** открой **«Входящие отчёты»**, изучи фотографии и эскиз, затем прими отчёт или верни его на исправление с пояснением. Изображение ручного эскиза можно открыть прямо в CAD.

**Разработчик:** имеет доступ к основной системе и CAD, управляет аккаунтами, проверяет состояние рабочего контура и может тестировать все роли.

## 5. GPS и HTTPS

Браузер должен получить разрешение на геолокацию. На телефонах GPS обычно работает только на защищённом HTTPS-сайте (исключение — localhost). Перед открытием приложения через HTTPS установи в `.env`:

```dotenv
COOKIE_SECURE=1
```

Затем пересоздай контейнер приложения:

```bash
docker compose up -d --no-deps app
```

Текущий встроенный Nginx-шлюз в Compose слушает HTTP на порту `WEB_PORT`; для публичного HTTPS используй внешний TLS reverse proxy или настрой TLS на шлюзе.

## 6. Диагностика и проверки

В панели разработчика нажми **«Проверить»** для базовой диагностики. Для проверки исходников выполни:

```bash
npm run check
```

Важно: GPS-панель показывает только точки, которые слесарь явно разрешил передавать; она не является скрытым трекером. Для свежих данных рабочая панель должна оставаться открытой.
