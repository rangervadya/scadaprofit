ScadaProfit 4.3.46 — автоматический редактируемый CAD-черновик

После распознавания приложение сразу создаёт CAD-проект и показывает его на основном экране. Основные геометрические маршруты отображаются чёрным; непроверенные кандидаты — оранжевым пунктиром. Черновик можно открыть в CAD-редакторе.

Редактор получил менеджер слоёв, поиск объектов, список труб/оборудования/подписей/размеров, выбор объекта из списка с переходом к нему на листе, автоматическое вписывание холста, свойства выбранного объекта, перетаскивание ветвей и вершин, undo/redo и редактируемые символы. Инструмент ручной трассировки обозначен как «Коррекция трассы» и остаётся вспомогательным.

Проверено: 22 Node.js CAD-теста; синтаксис JavaScript; примерный graph.json импортируется и формирует SVG предпросмотр.

Важно: автоматически созданный черновик не является подтверждённой инженерной схемой. Непроверенные кандидаты сохраняются отдельно и не включаются в чистовой экспорт до проверки. Соединения, условные обозначения, размеры и подписи нужно проверить специалисту.

Git-деплой: обновить файлы локально, commit/push; на сервере выполнить git pull --ff-only, docker compose build app, docker compose up -d --no-deps app.

Не меняются: vdgo/, compose.yaml, .env, Nginx/gateway, PostgreSQL, Ollama, Docker volumes и сторонние приложения.
