# Установка CAD Reconstruction Engine 4.3.5

1. Опубликуйте изменения в ветке `main` вашего Git-репозитория.
2. На сервере выполните:

```bash
cd /opt/scadaprofit
sudo git status
sudo git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps app
curl -sS http://127.0.0.1:3001/api/health
```

Проверьте `version: 4.3.5` и `pythonJobTimeoutMs: 2700000`. Затем обновите страницу браузера жёсткой перезагрузкой.

## Что изменилось в списке «Возможные разрывы»

Теперь там могут появляться короткие и неоднозначные концы, если они геометрически похожи на продолжение трубы. У каждого предложения показаны расстояние, соосность и причины проверки. Если один конец имеет несколько возможных партнёров, это будет отмечено. Кнопка «Добавить» создаёт ручной соединительный отрезок только после нажатия; автоматического слияния кандидатов нет. После принятия пары альтернативы, использующие те же концы, скрываются.

## Безопасность обновления

Не заменяйте `.env` и `.git`, не запускайте `docker compose down -v`. Ollama и её модели не пересоздаются командой `up -d --no-deps app`. Для просмотра логов: `sudo docker compose logs -f --tail=100 app`.

Кандидаты являются рекомендациями, а не доказанными соединениями. Проверьте исходное изображение перед включением в инженерный чертёж.
