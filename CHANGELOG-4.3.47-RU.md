# ScadaProfit 4.3.47 — точнее CAD-геометрия и исправление скачивания ВДГО

## CAD-генерация

- Проверенные локальным Qwen3-VL маршруты, прошедшие проверку исходными чернилами и OCR-маской, теперь попадают в итоговую структурированную CAD-модель. Ранее эти маршруты учитывались в промежуточной визуализации, но терялись при пересборке финального `clean.svg` / `drawing.dxf`.
- Фрагменты труб объединяются в непрерывные полилинии через узлы степени 2, включая реальные углы. В узлах ветвления соединяются только взаимно однозначные почти противоположные направления; неопределённые ветви остаются отдельными.
- Геометрия исходных фрагментов, узлы, точки поворота и идентификаторы исходных рёбер сохраняются. Автоматическая ортогонализация, подгонка к сетке и принудительное соединение пересечений не выполняются.
- По каждому ребру сохраняется измеренное свидетельство цвета ручки (синий / тёмный / смешанный / неизвестный). Цвет является только подсказкой и не определяет, является ли штрих трубой или исправлением.
- Размеры и текстовые подписи привязываются к трубе по расстоянию от всей рамки OCR, а не только от центра рамки. При нескольких одинаково близких трубах неоднозначность остаётся на ручную проверку.
- Инженерная проверка теперь отмечает в review случаи, когда геометрический конец трубы существенно не доходит до назначенного узла.
- Неизвестные условные обозначения по-прежнему требуют подтверждения инженером; автоматическое присвоение типа без надёжных признаков не включено.

## VDGO — заключение

- Скачивание PDF и DOCX переведено с `fetch()` + `Blob` + программного `a.click()` на обычную отправку формы в скрытый iframe. Это сохраняет пользовательское действие браузера и позволяет обработать ответ с `Content-Disposition: attachment` как штатную загрузку.
- Предпросмотр PDF оставлен отдельным режимом и продолжает открываться во вкладке.
- Backend возвращает безопасное имя файла с номером и датой заключения, включая UTF-8 `filename*`, а также заголовки запрета кеширования.
- Добавлены регрессионные тесты для фактического POST `/generate` и для браузерного пути скачивания.

## Что не менялось

Дизайн и вёрстка приложения, навигация, CAD-редактор, шаблон LPGCad R1, остальные модули, схема базы данных и Docker volumes не менялись. Визуальные стили формы VDGO не изменялись.

## Проверки

- Python CAD: 174 теста успешно.
- VDGO download regression: 3 теста успешно; включая реальный HTTP POST к `/generate` с проверкой PDF и `Content-Disposition`.
- Inline JavaScript в VDGO: `node --check` успешно.

## Развёртывание

Из корня проекта:

```bash
docker compose build app vdgo-backend
docker compose up -d --no-deps app vdgo-backend
```

Ollama, PostgreSQL, frontend VDGO, Nginx/gateway и volumes перезапускать не требуется.
