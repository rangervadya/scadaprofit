# Установка CAD Reconstruction Engine 4.3.0

В этой версии переработан отбор геометрии: OCR-рамки расширяются и исключаются из линейных кандидатов, если нет доказанного сквозного продолжения; связные линии оцениваются по графовой топологии; одиночные длинные штрихи остаются на DETAIL_REVIEW.

## Обновление GitHub

Загрузите содержимое полного архива в корень репозитория, сохраняя структуру каталогов. Не удаляйте `.git`, `.env` и серверные резервные копии. Полный архив содержит `public/styles.css`; не заменяйте только `processor.py`.

## Обновление сервера

```bash
cd /opt/scadaprofit
sudo git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps app
curl -sS http://127.0.0.1:3001/api/health
```

Ожидается `version: 4.3.0`. После анализа доступны диагностические файлы `primary-overlay.png`, `text-region-mask.png`, `ink-without-text-boxes.png` и `ink-inside-text-boxes.png` по ссылкам в интерфейсе.

## Проверка

Откройте исходную фотографию, повторите анализ и проверьте `PIPE_MAIN` и `DETAIL_REVIEW`. Версия не заменяет инженерную проверку: из одного геометрического штриха невозможно надёжно определить трубу без топологического/контекстного подтверждения.
