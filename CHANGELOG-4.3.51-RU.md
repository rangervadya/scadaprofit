# ScadaProfit 4.3.51

Сравнение редакций и наложение CAD на исходную фотографию.

## Изменения

- Добавлена история до 20 предыдущих редакций проекта; снимок сохраняется до изменения геометрического/инженерного содержимого.
- Добавлено сравнение текущей редакции с предыдущей: добавленные, удалённые и изменённые трубы, символы, подписи и размеры, а также новые замечания качества.
- Добавлена SVG-сверка исходной фотографии и CAD: подтверждённые трассы выделены зелёным, кандидаты на проверку — оранжевым пунктиром, узлы и символы показаны поверх фотографии.
- Сохранены все возможности 4.3.49 и 4.3.50: масштаб по размеру, порты оборудования, проверка качества и PDF-экспорт.

## Установка через GitHub

На компьютере в основной папке проекта:

```bash
git status
git add -A
git commit -m "ScadaProfit 4.3.51: CAD drawing improvements"
git push
```

На сервере в основной папке проекта:

```bash
git pull --ff-only
docker compose config --services
docker compose build app vdgo-backend
docker compose up -d --no-deps app vdgo-backend
docker compose ps
docker compose logs --tail=100 app vdgo-backend
```

Не удаляйте `.git`, `.env` и данные Docker volumes. Перед `git add -A` проверьте, что секреты и временные файлы не попали в коммит.

## Ограничения и проверка

- История ограничена 20 снимками на проект.
- Наложение на фото визуализирует совпадение и расхождения, но не перемещает и не корректирует геометрию автоматически.
- При отсутствии исходной фотографии endpoint сверки возвращает понятный ответ 404.
- Сравнение редакций — инструмент аудита; оно не заменяет проверку инженера.
