# Обновление CAD Sketch Converter до 4.3.14

## Что исправлено

- Упрощён рабочий экран: убраны лишние верхние подписи и поясняющий декор, уменьшены отступы и визуальный шум.
- Левая панель работает как адресный архив: поиск по улице показывает дома этой улицы; поиск по дому раскрывает его входящие эскизы; поиск по названию схемы фильтрует входящие.
- Слесарь выбирает улицу и дом, прикрепляет фото и нажимает «Отправить фото в выбранный дом». Сервер сохраняет оригинал в статусе `pending`; обработка Qwen при загрузке не запускается.
- Специалист открывает эскиз из входящих и отдельно нажимает «Преобразовать в CAD».
- OCR компактных таблиц сохраняет отдельные ячейки и переводит их координаты из crop в пиксели исходного листа. Экспорт текста привязывается к левому краю исходного bbox, а не к центру всей строки.
- Маршруты Qwen, которые не прошли подтверждение для основного слоя, остаются видимыми пунктиром в `QWEN_REVIEW`; они не подмешиваются автоматически в основной `PIPE_MAIN`.
- Сохраняются существующие проверки чернильной непрерывности, текста, направления и конфликтующих вариантов соединения.

## Ограничение по соединению линий

В журнале предыдущего задания было 19 кандидатов продолжения, но 0 кандидатов с высокой уверенностью. Такие пары нельзя безопасно соединить автоматически только по близости концов: это может склеить два соседних трубопровода. Они остаются на ручную проверку в панели «Узлы и соединения». Неподтверждённые трассы Qwen доступны на пунктирном слое проверки.

## Какие файлы заменить в GitHub

Заменить в ветке `main` следующими файлами, сохранив пути:

- `processor.py`
- `server.js`
- `package.json`
- `tests/test_engine.py`
- `public/app.js`
- `public/index.html`
- `public/styles.css`

Сам ZIP в репозиторий загружать не нужно. После замены сделать `Commit changes`.

## Команды на сервере

```bash
cd /opt/scadaprofit

git pull --ff-only origin main

sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps app
sudo docker compose ps

curl -sS http://127.0.0.1:3001/api/health
```

Ожидаемая версия API: `4.3.14`.

`--no-deps app` пересоздаёт только приложение и не перезапускает Ollama. Не выполнять `docker compose down -v` и не удалять тома.

## Проверка

Локально перед упаковкой выполнено `npm run check`: синтаксис `server.js` и `public/app.js`, компиляция Python и 83 теста пройдены.

После установки проверить рабочий путь:

1. Найти улицу и дом.
2. Выбрать дом, приложить фото и отправить.
3. Убедиться, что фото появилось во входящих со статусом «Входящая», а Qwen не запустилась.
4. Открыть входящую схему и отдельно нажать «Преобразовать в CAD».
5. Проверить таблицу в левом верхнем углу исходника: значения должны оставаться в отдельных исходных позициях.
6. Проверить сплошной основной слой и пунктирные слои `DETAIL_REVIEW` / `QWEN_REVIEW`.

## Доступ

Адресный архив общий для всех, кто имеет доступ к приложению. Раздельные учётные записи и роли «слесарь/специалист» в этой версии не реализованы; не публиковать приложение в открытый интернет без отдельной авторизации.
