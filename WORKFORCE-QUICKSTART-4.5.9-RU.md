# ScadaProfit 4.5.9 — планирование улиц и домов

## Что добавлено

Приёмщик теперь может самостоятельно назначать выезды слесарям. В левом меню его кабинета появилась вкладка «План работ». В форме выбираются название работы, улица, дата и слесарь; номера домов перечисляются по одному на строку. Допускается до 100 домов за одно назначение.

Сервер создаёт для каждого дома отдельное задание. Это важно: у каждого адреса собственные кнопки «Начать обход», «Прошёл дом», «Пришёл в офис», отдельная ручная схема и собственные фото дефектов. Все задания из одной отправки связаны общим идентификатором группы и отображаются одной группой в расписании диспетчера.

В кабинете слесаря назначения видны по датам. Блок «Сегодня» отображается первым; далее показываются завтрашние, будущие и просроченные назначения. Слесарь видит только задания, назначенные его аккаунту. GPS не используется.

Старые одиночные назначения продолжают работать.

## Обновление

В корне проекта, где находится основной `compose.yaml`, выполни:

```bash
docker compose build --no-cache app
docker compose up -d --no-deps --force-recreate app
docker compose restart gateway
```

Постоянные Docker-тома с аккаунтами, заданиями, отчётами и CAD-проектами не удаляй.

## Ручная проверка после обновления

1. Войди под аккаунтом приёмщика.
2. Открой «План работ».
3. Выбери дату, слесаря и улицу, впиши несколько домов каждый с новой строки и назначь выезд.
4. Войди под тестовым слесарем: в «Мои задания» должны появиться все адреса под заголовком «Сегодня» или выбранной датой.
5. Отметки и отправка схем/фотографий остаются индивидуальными для каждого дома.
