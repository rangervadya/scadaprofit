# История изменений

## 4.2.3
- Перестроен основной CAD-экспорт: Qwen3-VL выделяет семантические осевые маршруты труб, а не используется только как OCR поверх пиксельной трассировки.
- Добавлена отдельная структурированная задача Qwen для маршрутов, углов и ответвлений с исключением рукописных цифр, размерных линий, выносок, стрелок и символов.
- OCR переведён на четыре перекрывающихся увеличенных фрагмента; рамки умеренно уверенных распознаваний тоже исключают буквы/цифры из геометрического канала.
- Когда семантические маршруты доступны, SVG/DXF использует их на `PIPE_MAIN`; OpenCV-кандидаты остаются на замороженном `DETAIL_REVIEW`.
- Если Qwen не вернул маршруты, слой PIPE_MAIN остаётся пустым, а пиксельные кандидаты доступны только в DETAIL_REVIEW и исходном оверлее.
- 23 автоматических теста: масштабирование OCR-фрагментов, подавление штрихов низкоуверенного текста, масштабирование Qwen-маршрутов и приоритет семантических полилиний в экспорте.

## 4.2.2
- Введён отдельный отбор основных трасс по непрерывным путям графа вместо отбора целых связных компонентов.
- Удалены короткие присоединённые штрихи символов из чистого предпросмотра; оригинальные кандидаты сохранены для ручной проверки.
- В DXF добавлены слои `PIPE_MAIN` и замороженный `DETAIL_REVIEW`.
- Сохранение коротких соосных продолжений труб через узлы.
- Снижение дрожания полилиний с помощью RDP-упрощения.
- Исправлено объединение LSD/Hough, когда оба детектора находят противоположные края одного толстого штриха; раздельные параллельные линии с внутренним белым зазором сохраняются.

# Изменения 4.2.1

- Исправлено дублирование рукописных надписей: подтверждённые OCR-штрихи в текстовой рамке не экспортируются как линейные сегменты; вместо них создаётся редактируемый CAD TEXT.
- Продолжающиеся по обе стороны OCR-области линии сохраняются, чтобы подпись не разрывала трассу трубы.
- Высокоуверенные результаты Tesseract также могут автоматически становиться CAD-текстом.
- SVG и DXF теперь используют согласованный лист A3 с рамкой, полем чертежа и основной надписью. DXF выводится в миллиметрах, со слоями SHEET, PIPE_CANDIDATES, VERIFIED_TEXT и NOTES.
- Добавлена консервативная CAD-очистка полилиний: удаление почти коллинеарных вершин и выравнивание только почти ортогональных углов.
- Добавлены тесты на удаление штрихов букв с сохранением сквозной трубы. Всего 12 тестов.

# Изменения 4.2.0

- Добавлен OCR рукописных подписей через Qwen3-VL в локальном Ollama; Tesseract остаётся запасным и дополнительным движком.
- Уверенные распознавания Qwen предвыбраны для включения в CAD-экспорт; подписи можно редактировать и отключать галочкой.
- Переработано объединение повторных LSD/Hough-сегментов: учитываются направление, расстояние между осями, перекрытие и поддержка чернил в промежутке.
- Параллельные линии с отдельными штрихами сохраняются; OCR-рамки не влияют на классификацию длинных компонентов и не удаляют участки трассы.
- Уменьшена минимальная длина кандидатов, короткие линейные продолжения больше не пропадают из основного вида и экспорта.
- Уменьшена толщина SVG до 0,7 единицы листа и задана толщина DXF 0,13 мм.
- Версия приложения: 4.2.0.

## Изменения 4.1.1

- Исправлена причина отсутствия стилей и JavaScript при открытии приложения по HTTP в локальной сети.
- Убрана CSP-директива `upgrade-insecure-requests`, которую Helmet добавлял по умолчанию. Браузер больше не должен переписывать `/styles.css` и `/app.js` в HTTPS.
- CSP теперь задан явно, с сохранением ограничений на источники скриптов, стилей, изображений и подключений.
- Отключены неуместные для HTTP LAN-заголовки COOP, Origin-Agent-Cluster и HSTS.
