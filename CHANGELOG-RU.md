# Изменения 4.3.6

- Конкурирующие кандидаты группируются по общему конечному узлу; интерфейс показывает ID вариантов, рейтинг и разницу оценок.
- Добавлен предпросмотр отдельного соединения и одновременное сравнение альтернатив поверх исходного чертежа.
- Подтверждение кандидата отправляется на сервер с проверкой ID кандидата, пары узлов и состояния открытых концов.
- Подтверждённое пользователем соединение атомарно сохраняется в `graph.json` как ручное ребро и запись `confirmedConnections`.
- Альтернативы, использующие уже соединённые узлы, удаляются из актуального списка кандидатов.
- Добавлен API восстановления графа сохранённого задания и автоматическое восстановление по URL `?job=<uuid>`.
- Ручные соединения остаются отдельными объектами `source=manual`, включаются в SVG/DXF и сохраняются в JSON.
- Неоднозначные соединения по-прежнему не выбираются автоматически; рейтинг не трактуется как вероятность.

- Каталог заданий перенесён из `/tmp` в `/data/cad-reconstruction-jobs` на отдельный Docker named volume `cad_jobs`, чтобы подтверждённые правки переживали пересоздание контейнера.
