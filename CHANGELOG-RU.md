# Изменения ScadaProfit 4.3.28

- Удалён провайдер Yandex Cloud AI по просьбе пользователя; при старте приложения удаляется только его старый закрытый файл настроек `yandex-ai-settings.json`.
- Добавлен OpenRouter с бесплатной мультимодальной моделью `nvidia/nemotron-3.5-super-vl:free`.
- OpenRouter выполняет один whole-image OCR проход и отдельное предложение трубных полилиний. Координаты OCR и труб валидируются по границам исходного изображения.
- Маршруты OpenRouter проходят существующую проверку чернильной опорой и топологией; при ошибке/отсутствии результата используется локальный Qwen. Tesseract остаётся дополнительным распознавателем.
- Добавлены серверное хранение ключа с правами 0600, настройки провайдера в интерфейсе, тест по открытой схеме и удаление только настроек OpenRouter.
- Локальный Qwen и Tesseract сохранены; Yandex API больше не вызывается.
- Не изменялись `vdgo/`, `compose.yaml`, Nginx, PostgreSQL и Docker volumes.
- В бесплатном endpoint действует лимит OpenRouter 50 запросов/сутки и 20 запросов/минуту; запросы могут логироваться для улучшения модели NVIDIA.
# ScadaProfit 4.3.27

- Исправлена авторизация Yandex Vision OCR для сервисного аккаунта: заголовок `x-folder-id` больше не передаётся, поскольку каталог определяется по сервисному аккаунту автоматически.
- Для мультимодального API Yandex оставлен документированный `OpenAI-Project` с ID каталога; лишний `x-folder-id` удалён.
- Добавлены регрессионные тесты: Vision OCR вызывается с API-ключом без `x-folder-id`, в том числе когда ID каталога не передан в саму OCR-функцию.
- Сохраняется cloud-first порядок 4.3.26: Yandex Vision вызывается до локальных OCR-плиток Qwen; Qwen и Tesseract остаются резервными/дополнительными движками.
- VDGO, Compose, Nginx, PostgreSQL и Docker volumes не изменяются.

# ScadaProfit 4.3.26

- Исправлен порядок OCR: при включённом Yandex Vision он вызывается первым на всё изображение, без ожидания девяти локальных Qwen-плиток.
- Локальный Qwen3-VL сохранён как резерв: запускается, если Yandex OCR выключен, завершился ошибкой или не вернул аннотаций.
- Tesseract остаётся дополнительным OCR-источником и запускается после основного распознавания.
- Мультимодальная трассировка Yandex Qwen по-прежнему выполняется после завершённого OCR; при отсутствии пригодных маршрутов сохраняется резервный локальный Qwen.
- Изменения ограничены основным ScadaProfit; VDGO, Compose, Nginx, PostgreSQL и Docker volumes не изменяются.

# ScadaProfit 4.3.25

## Дополнительный облачный провайдер Yandex Cloud AI
- Добавлен необязательный Yandex Vision OCR в режиме `handwritten` для русских/английских рукописных и печатных подписей. Все возвращённые подписи остаются непроверенными кандидатами и не попадают в геометрию труб.
- Добавлена мультимодальная модель Yandex AI Studio `qwen3.6-35b-a3b` для извлечения полилиний труб из фотографии с координатами исходного изображения.
- Маршруты модели проходят текущую проверку чернильной опорой, OCR-маской и геометрией OpenCV. Если ни один облачный маршрут не прошёл проверку, выполняется локальный Qwen fallback.
- Добавлены серверные API-настройки Yandex, UI для сохранения ключа и Folder ID, раздельное включение OCR/трассировки, smoke-test по выбранной схеме и удаление только облачных настроек.
- API-ключ сохраняется в закрытой папке существующего тома данных ScadaProfit с правами `0600`; Compose и `.env` не меняются.
- Локальные Qwen3-VL и Tesseract сохранены и продолжают работать. Облачный режим по умолчанию выключен, пока пользователь явно не включит его.
