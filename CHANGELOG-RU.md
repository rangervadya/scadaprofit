# Изменения 4.3.4

- Общий тайм-аут дочернего Python-процесса увеличен с 15 до 45 минут: `PYTHON_JOB_TIMEOUT_MS=2700000`. Его можно переопределить переменной окружения; минимальное допустимое значение — 60 секунд.
- Запуск Python переведён с `execFile` на `spawn`. `stdout` результата по-прежнему ограничен 16 МиБ; `stderr` читается потоково, без накопления неограниченного буфера в памяти.
- Прогресс Python немедленно отправляется в `docker compose logs -f app`: предварительная обработка, каждый OCR-фрагмент, каждая строка рукописной заметки, каждый PIPE-фрагмент, построение графа и экспорт.
- Для каждого задания создаётся timestamped `progress.log`. URL журнала возвращается и при ошибке (`progressUrl`) и добавляется к сообщению об ошибке.
- Тайм-ауты отдельных запросов Ollama (`QWEN_OCR_TIMEOUT=180` и `QWEN_PIPE_TRACE_TIMEOUT=240`) не изменялись.
- При превышении общего лимита Node.js отправляет Python `SIGTERM`; если процесс не завершился за 5 секунд, отправляется `SIGKILL`.

## Предыдущий выпуск: 4.3.3

- Геометрическая OCR-маска использует источник и уверенность: Qwen ≥25, построчные блоки Qwen целиком, Tesseract ≥55. Сомнительные OCR-объекты остаются в TEXT_REVIEW, но не вырезают автоматически исходные чернила.
- Сетка Qwen OCR и pipe tracing — 3×3.
- Исправлена генерация `joinCandidates`: исключены самостыковки, соединения конца с серединой другого отрезка и пары с боковым смещением.
