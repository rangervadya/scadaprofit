# Изменения 4.1.1

- Исправлена причина отсутствия стилей и JavaScript при открытии приложения по HTTP в локальной сети.
- Убрана CSP-директива `upgrade-insecure-requests`, которую Helmet добавлял по умолчанию. Браузер больше не должен переписывать `/styles.css` и `/app.js` в HTTPS.
- CSP теперь задан явно, с сохранением ограничений на источники скриптов, стилей, изображений и подключений.
- Отключены неуместные для HTTP LAN-заголовки COOP, Origin-Agent-Cluster и HSTS.
- Версия приложения: 4.1.1.
