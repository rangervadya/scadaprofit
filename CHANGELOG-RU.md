# Изменения 3.0.0

- Старый Qwen JSON graph/route flow исключён из пользовательского приложения.
- Добавлено локальное выделение общей маски чернил через OpenCV HSV.
- Добавлена OCR-детекция текстовых областей через Tesseract `eng+rus`.
- Добавлена отдельная маска текста и остаточная маска линий.
- Маски являются точным разделением исходных ink-пикселей: не строятся искусственные соединения, не выполняется сглаживание или скелетизация.
- Добавлены просмотр оригинала, маски текста, маски линий, цветное наложение, статистика и скачивание PNG/JSON.
- Добавлены настройки цвета чернил, OCR confidence и отступа текстовой области.
- Ollama не вызывается; существующий сервис и named volume оставлены в Compose для безопасного перехода.
