# Изменения 4.3.5

- Поиск потенциальных стыковок теперь рассматривает открытые концы `line_structure` и `ambiguous`, а не только основной класс.
- Короткие сегменты от 8 px могут попасть в список ручной проверки; жёсткий минимум длины 25 px снят для диагностических кандидатов.
- Диапазон поиска кандидатов расширен до 4,5–45 px; допускается поперечное отклонение до 8 px для списка проверки. Это не меняет автоматическую кластеризацию и не создаёт автоматических соединений.
- Для каждого кандидата сохраняются направления, боковое отклонение, длины фрагментов, ink support, OCR overlap, причины отбора и предупреждения.
- Конкурирующие пары для одного открытого конца помечаются `competing_candidate`; после ручного добавления альтернативы с использованными концами убираются из списка.
- Кандидаты около границы изображения отмечаются отдельно. Компоненты `text_or_annotation` исключены.
- Сводка JSON дополнена количеством кандидатов высокого приоритета, требующих проверки, конфликтующих альтернатив и открытых конечных узлов.
- Автоматическое соединение пересечений по-прежнему выключено.

## Сохранено из 4.3.4

- Тайм-аут Python-процесса — 45 минут (`PYTHON_JOB_TIMEOUT_MS=2700000`).
- Потоковые логи `[JOB]`, `[OCR]`, `[PIPE]`, `[CAD]`, `[EXPORT]` и `progress.log` на каждое задание.
- Тайм-ауты отдельных запросов Ollama остаются 180/240 секунд.
