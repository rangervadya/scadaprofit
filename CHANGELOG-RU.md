# Изменения 2.7.0

- Удалён старый интерфейс трассировки OpenCV и CAD-рендеринга.
- Удалён endpoint `/api/convert` и зависимости Python/OpenCV/Tesseract/ezdxf/cairosvg.
- Приложение сфокусировано на двух запросах Ollama: фото → граф JSON, граф JSON → путь.
- Добавлен сырой prompt editor для обоих этапов; пользователь может изменить огромный маршрутный промпт.
- Дословный `message.content` каждого вызова выводится отдельно.
- Визуализатор показывает серый входной граф и оранжевый кандидатный ответ Qwen; шаги пути подсвечиваются по одному.
- `localValidation.warnings`, независимая длина, исходная длина и разница выводятся в UI и Docker-лог.
- Если Qwen выдал `status: ok`, но независимая проверка не прошла, результат остаётся видимым только как кандидат и помечается как неподтверждённый.
- Добавлены автоматические тесты для directed graph, направления, точности координат, длины и неоднозначного пути.
