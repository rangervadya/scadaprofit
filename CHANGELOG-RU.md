# Изменения 4.3.2

## Топология труб
- Короткие ветви сохраняются, если они подключены к компоненте, уже классифицированной как трубопровод, имеют минимум 14.5 px длины (для изображения 1280×906), достаточную поддержку исходными чернилами и не пересекают OCR-маску. Отдельные короткие символы остаются на проверке.
- Соосный разрыв до 19 px проверяется по исходным пикселям только внутри середины зазора. Дилатация концов соседних сегментов больше не может сама по себе служить доказательством соединения.
- Семантические маршруты Qwen проверяются посегментно: сегмент, попавший в текстовую область, не должен автоматически уничтожать остальные подтверждённые части маршрута.

## Рукописные блоки
- Нумерованные заметки с плотной левой колонкой автоматически делятся на отдельные строки по исходному изображению. На тестовом фрагменте из предыдущего скриншота найдено 10 полос строк.
- Каждая строка получает отдельный короткий Qwen OCR-запрос, включая номер, буквы, цифры и коды. Тайм-аут распределяется между запросами, чтобы несколько строк не могли каждая использовать весь общий лимит.
- Если отдельная строка не распознана или запрос завершился ошибкой, создаётся `?` в `TEXT_REVIEW` с полной рамкой строки, чтобы штрихи не стали трубами.
- `handwritten-text-blocks.png` показывает границы каждой найденной строки; в `graph.json` добавлены счётчики найденных, возвращённых и проверенных строк.

## Совместимость и проверки
- Сохранены `public/index.html`, `public/app.js` и исходный `public/styles.css`; версии CSS/JS в URL обновлены для сброса старого кеша браузера.
- `npm run check`: 61 автоматический тест пройден.
- Проверка на скриншотном фрагменте, уже доступном в этой сессии: детектор заметок выделил один блок 256×193 px и 10 строк; это не заменяет проверку на исходной фотографии полного разрешения.
