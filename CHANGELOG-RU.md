# Изменения 2.9.0

- Vision-этап теперь извлекает независимые полилинии `strokes`, а не пытается сразу решить инженерную топологию.
- Сервер детерминированно создаёт граф из последовательных координат каждого штриха.
- Между разными штрихами соединения не угадываются и не объединяются автоматически.
- Raw JSON показывает ответ модели; редактор и визуализатор показывают граф, полученный из полилиний.
- Визуальный промпт упрощён: сначала локализация штрихов, инженерная интерпретация позже.
- Лимит ответа увеличен до 5000 токенов; JSON Schema задаёт ограниченную структуру полилиний.
