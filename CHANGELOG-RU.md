# Two Mask Lab 3.3.0

- Добавлен редактор OCR-подписей с миниатюрой исходного фрагмента.
- Два независимых действия на каждую подпись: удалить рукописные пиксели из маски линий и вывести проверенный текст печатным шрифтом.
- OCR-результаты больше не печатаются автоматически: ошибочные рукописные цифры не подменяются молча.
- Исправленные подписи сохраняются в чистый SVG; поддерживается угол поворота.
- Кнопка «Применить подписи» повторно строит маски без повторного запуска OCR.
- Исходные растровые маски остаются доступны без изменений.

- Добавлено ручное прямоугольное выделение рукописных областей прямо на оригинальной фотографии, включая текст, пропущенный OCR.
- Для каждой области показывается миниатюра исходника; «убрать рукопись» и «печатать» работают независимо.
