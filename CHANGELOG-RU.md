# CHANGELOG

## 4.0.0 — CAD Reconstruction Engine

- Удалён старый pipeline двух масок в качестве источника геометрии.
- Геометрические сегменты извлекаются OpenCV LSD и Hough.
- OCR вынесен в независимые аннотации; OCR-боксы не вычитаются из геометрии.
- Строится граф узлов и сегментов; конечные точки в пределах 4.5 px снаппятся к общей координате узла.
- Пересечения не соединяются автоматически.
- Добавлены предложения коротких соосных разрывов с ручным подтверждением.
- Добавлен браузерный редактор: фильтр основных/всех кандидатов, перемещение узлов, ручное соединение узлов, выключение сегментов, проверка OCR-подписей.
- Добавлен экспорт текущего графа в SVG, DXF, JSON и печать в PDF.
- Ollama и именованный том сохранены в Compose; геометрический pipeline от модели не зависит.
