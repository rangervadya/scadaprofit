# ScadaProfit 4.3.23 — обновление локального проекта и сервера

## Что меняет версия 4.3.23

Теперь основной путь начинается во вкладке «Схемы домов»:

1. Слесарь загружает фотографию в папку выбранных улицы и дома. Загрузка сохраняет оригинал и не запускает Qwen.
2. Сотрудник офиса выбирает в дереве адресов нужную схему и нажимает «Преобразовать в чистовой чертёж».
3. После окончания обработки ScadaProfit автоматически создаёт или обновляет связанный CAD-проект, подставляет адрес из архива и показывает лист LPGCad R1 в карточке схемы.
4. Кнопка «Редактировать» открывает этот же проект в ручном CAD. Там можно править линии/узлы, строить ответвления, добавлять символы, подписи и размеры, задавать группы стояков, отменять/повторять действия и сохранять чертёж.
5. Ссылка в редакторе возвращает к исходной схеме дома. Повторное открытие не создаёт копию. Повторный импорт не затирает CAD-проект после ручных изменений.

## Важные ограничения

- Автоматический результат — инженерный черновик, не автоматическое подтверждение безопасности газовой системы.
- В CAD переносятся выбранные основные линии и Qwen-маршруты, прошедшие отдельную проверку по исходным чернилам. Сомнительные линии/соединения остаются на проверку.
- Неподтверждённые символы, диаметры и размеры не придумываются.
- Адрес подставляется из выбранной улицы и дома. Подъезд, фамилии, группы стояков и номера квартир заполняются только при наличии подтверждённых данных.
- Если после распознавания нет подтверждённой геометрии, интерфейс прямо сообщает, что чистовой чертёж не готов; можно продолжить вручную поверх подложки.

## Локальный VS Code

1. Сделай отдельную резервную копию своего локального проекта.
2. Распакуй `ScadaProfit-4.3.23-house-workflow.zip` в корень локального проекта поверх версии 4.3.22, соглашаясь на замену файлов из архива.
3. Не заменяй `.env`, `.git`, `vdgo/`, `compose.yaml`, `nginx-unified.conf` и файлы томов/данных.
4. В терминале VS Code выполни:

```bash
npm run check
```

5. Проверь вручную: открой «Схемы домов» → найди улицу/дом → выбери входящую схему → «Преобразовать» → дождись результата → «Редактировать» → внеси тестовое изменение → дождись «Сохранено» → вернись к схеме дома и открой редактор снова.
6. Добавь в Git только файлы обновления (можно через терминал VS Code):

```bash
git add CHANGELOG-RU.md UPGRADE-GIT-4.3.23-RU.md UPDATE-MANIFEST-4.3.23.txt package.json server.js manual-cad-core.js public/app.js public/index.html public/manual-cad.html public/manual-cad.js public/styles.css tests/manual-cad.test.js
git status --short
git commit -m "Connect house scheme conversion to LPGCad manual editor"
git push origin main
```

Перед commit убедись, что в списке нет `.env`, `vdgo/`, `compose.yaml`, Nginx-конфигурации, архивов, фотографий заказчиков или данных PostgreSQL.

## Сервер после push в GitHub main

Сначала убедись, что на сервере нет важных локальных изменений. Команды ниже рассчитаны на чистую ветку `main`, синхронизированную с origin/main:

```bash
cd /opt/scadaprofit
git status --short --branch
git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps --force-recreate app
sudo docker compose ps
curl -sS http://127.0.0.1:3001/api/health
```

В `/api/health` ожидается `"version":"4.3.23"`. Затем проверь в браузере `/` и `/vdgo/`.

**Не выполняй** `docker compose down`, `docker compose up -d` без указания сервиса, `git reset --hard`, `git clean -fd` и команды удаления томов. Эта инструкция обновляет только контейнер `app`; gateway, VDGO Frontend/Backend, PostgreSQL и Ollama не пересоздаются.

## Файлы и тесты

Архив содержит только файлы приложения ScadaProfit и инструкцию. Он не содержит `vdgo/`, `compose.yaml`, `nginx-unified.conf`, `.env`, БД или томов.

После распаковки ожидается успешный `npm run check`. Реальную Docker-сборку и выполнение модели Qwen на целевом сервере нужно подтвердить там отдельно.
