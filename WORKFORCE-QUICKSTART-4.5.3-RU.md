# ScadaProfit 4.5.3 — обновление, аккаунты и рабочий процесс

## 1. Обновление

В каталоге проекта:

```bash
docker compose build app
docker compose up -d --no-deps app
docker compose restart gateway
```

При первом развёртывании:

```bash
docker compose up -d --build
```

Не удаляй постоянный том `cad_jobs`: в нём хранятся аккаунты, задания, отчёты и CAD-проекты.

## 2. Вход и аккаунты

Каждый сотрудник входит только по персональному логину и паролю. Нельзя выбрать чужой аккаунт или роль вместо ввода пароля.

Руководитель создаёт аккаунт через вкладку «Создать аккаунты»: указывает имя и фамилию, выбирает роль «Слесарь» или «Приёмщик». Система выдаёт уникальный логин и случайный пароль.

Вкладка «База аккаунтов» показывает сотрудников, ФИО, роли и логины. Пароли хранятся в виде криптографических хешей, поэтому старый пароль нельзя прочитать из базы. Кнопка «Выдать новый пароль» заменяет старый случайным новым, завершает текущие сессии сотрудника и показывает новые данные для копирования.

## 3. Рабочий процесс слесаря

Руководитель назначает дату, улицу, дом, слесаря и инструкции.

Слесарь выполняет последовательность кнопками:

1. «Начать обход дома».
2. «Отметить: прошёл этот дом».
3. «Отметить: пришёл в офис».
4. Прикрепить только изображение ручной схемы и отправить его.

Фотографии самого объекта и GPS не требуются. Геолокация не запрашивается и не сохраняется. Руководитель видит только отметки кнопок и время событий.

## 4. Уведомление, CAD и заключение

После отправки ручного эскиза сервер ставит его в штатную очередь автоматической реконструкции. Схема привязывается к адресу. Приёмщик получает уведомление с улицей и домом, видит оригинальный эскиз и предпросмотр CAD.

Приёмщик может открыть CAD-редактор, показать или скрыть оригинал, исправить линии, узлы, подписи и сохранить чертёж. Кнопка «Добавить в заключение» доступна в уведомлении после готовности CAD, а также непосредственно в редакторе для схемы, полученной от слесаря.

После переноса в «Заключение» включается именно сохранённый CAD-проект приёмщика (включая ручные правки), а не только первоначальный автоматический предпросмотр. Там доступны предпросмотр и актуальный SVG/DXF.

Пункт «Заключение» и самостоятельная форма технического заключения сохранены. Её по-прежнему можно открыть и заполнить вручную — перенос схемы из уведомления не является обязательным.

## 5. Роли

- **Слесарь:** личные задания, кнопки этапов, отправка ручного эскиза.
- **Приёмщик:** уведомления, CAD-редактор, перенос в заключение, приёмка или возврат на исправление.
- **Руководитель (до двух аккаунтов):** назначения, контроль отметок, создание аккаунтов слесарей и приёмщиков, база логинов и переиздание паролей.
- **Разработчик:** полный доступ к ролям, заданиям, отчётам, тестированию и настройкам.

## 6. Проверки

Запуск проверок:

```bash
npm run check
```

Для доступа через интернет настрой HTTPS и `COOKIE_SECURE=1` в `.env`. Полный Docker-запуск нужно проверить на целевом сервере, где доступен Docker и установлены внешние OCR/AI-зависимости.


## Исправление 4.5.3: отправка ручного эскиза

В версии 4.5.3 исправлено сохранение загруженной картинки, когда временная папка `/tmp` и постоянный том `/data` находятся на разных файловых системах. Для обновления достаточно пересобрать приложение и перезапустить gateway по командам выше. Том `cad_jobs` не удалять.
