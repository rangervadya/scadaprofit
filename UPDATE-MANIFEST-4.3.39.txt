Do not deploy by replacing the whole project directory on a live server.
Use the established Git workflow and rebuild only `app`:
  docker compose build app
  docker compose up -d --no-deps app

Do not restart/recreate Ollama, VDGO, gateway, PostgreSQL, or any other application.
ScadaProfit sends Qwen request-level `num_ctx`, `num_batch`, `num_thread`, and
`keep_alive` options explicitly to the existing Ollama service.
