# Примечание о прежнем Ollama Structured Outputs (2.4.x)

Этот документ относится к прежнему CAD-режиму 2.4.x и оставлен только для истории.

В версии 2.5.0 структурированный вывод Ollama больше не используется для извлечения координат труб. В реальных тестах Qwen3-VL возвращала корректный по JSON Schema объект с пустыми массивами линий/узлов. Это демонстрировало, что валидный JSON не гарантирует распознавания геометрии.

Вместо этого 2.5.0 получает линии из исходных пикселей через OpenCV: выделение чернил → thinning → граф скелета → векторные пути. Ollama остаётся необязательным сервисом совместимости и не участвует в основной трассировке.

См. `TRACE-PIPELINE-RU.md` и `README.md`.
