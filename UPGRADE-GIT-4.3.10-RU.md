# Обновление до 4.3.10

## Что входит

- Более устойчивое выделение рукописных блоков и построчный OCR для блоков от трёх строк; сохранено распознавание длинных списков.
- Убран непрозрачный бежевый прямоугольник за сомнительными OCR-подписями. Сомнительные подписи не удаляются: их можно показать и проверить отдельно.
- Неподтверждённые геометрические кандидаты показываются пунктиром на отдельном слое `DETAIL_REVIEW`, не превращаясь автоматически в основные трубы.
- Упрощён интерфейс и добавлена общая библиотека `Улица → Дом → Схемы`.
- Новые схемы автоматически сохраняются в выбранную папку дома. Уже существующее открытое задание можно назначить дому кнопкой «Переместить открытую схему в этот дом».
- Адресная библиотека хранится в `${DATA_DIR}/.private/address-library.json` внутри существующего именованного тома `cad_jobs`.

## Обновление через GitHub

1. Распакуйте архив и загрузите в репозиторий только перечисленные в нём файлы, сохранив пути.
2. Создайте commit в ветке `main`.
3. На сервере выполните:

```bash
cd /opt/scadaprofit
git pull --ff-only origin main
sudo docker compose config --quiet
sudo docker compose build app
sudo docker compose up -d --no-deps app
sudo docker compose ps
curl -sS http://127.0.0.1:3001/api/health
```

Ollama и Qwen не пересобираются и не перезапускаются. Не выполняйте `docker compose down -v` и не удаляйте том `cad_jobs`: в нём находятся задания, исходные изображения, результаты и адресная библиотека.

## Использование библиотеки

1. Создайте улицу кнопкой `+`.
2. Выберите улицу и добавьте дом.
3. Выберите дом, загрузите фото эскиза и нажмите «Распознать и сохранить в папку дома».
4. Другой специалист открывает приложение, раскрывает улицу и дом, затем нажимает название схемы. Откроются исходное фото и векторный результат.
5. Старые задания автоматически не распределяются по домам. Откройте старое задание по его ссылке, выберите дом и нажмите «Переместить открытую схему в этот дом».

## Безопасность и ограничения

- В этой версии библиотека общая для всех, кто имеет сетевой доступ к приложению. Вход по учётным записям и роли «слесарь/специалист» ещё не реализованы. Не публикуйте сервис в открытом интернете без отдельной авторизации и ограничения доступа.
- Пунктир `DETAIL_REVIEW` — это только найденные алгоритмом кандидаты; это не подтверждённые трубопроводы. Проверяйте их по исходному листу.
- Неоднозначные соединения не объединяются автоматически без подтверждения исходными пикселями. Результат требует инженерной проверки.
- Количество запросов Qwen и покрытие 3×3 не сокращались. В `graph.json` записываются времена этапов и статистика запросов; фактическое ускорение нужно измерить на том же чертеже и сервере.
