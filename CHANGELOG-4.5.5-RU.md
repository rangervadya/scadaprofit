# ScadaProfit 4.5.5 — исправлено формирование заключения с выездными схемами

## Исправление

Устранена ошибочная проверка длины поля `workforce_schemes_json`. Ранее общий лимит 500 символов для текстовых полей применялся к служебному JSON, содержащему CAD-предпросмотры в PNG/base64. Из-за этого заполненное заключение блокировалось сообщением «Поле workforce_schemes_json слишком длинное».

Теперь:
- `workforce_schemes_json` исключён из проверки длины обычного текста;
- размер структурированного payload контролируется отдельным лимитом 180 МБ;
- для каждой схемы по-прежнему проверяются JSON-структура, base64, PNG-формат, размеры изображения и общий лимит вложений;
- ограничения обычных текстовых полей заключения сохранены без ослабления;
- выбранные схемы по-прежнему вставляются в пункт 7 PDF и Word.

## Обновление

```bash
docker compose build vdgo-backend app vdgo-frontend
docker compose up -d --no-deps vdgo-backend app vdgo-frontend
docker compose restart gateway
```

Постоянные тома `cad_jobs` и `vdgo_postgres_data` не удалять.
