# ScadaProfit 4.5.10 — единая приёмка и адресное включение материалов в заключение

## Навигация и кабинет приёмщика

- Ссылка «Команда» постоянно находится в левой навигации основных модулей и располагается выше «Настроек»; переход в настройки больше не нужен для доступа к рабочей панели.
- Входящие ручные эскизы и фотографии дефектов объединены в один список уведомлений с фильтром по улице, дому, сотруднику и комментарию. Тип материала и его статус видны в карточке.
- Приёмщик проверяет CAD-схему и фото дефектов в одном интерфейсе, не переключаясь между отдельными вкладками очередей.

## Только выбранный дом попадает в заключение

- Убрана постоянная общая витрина всех готовых схем на странице «Заключение». Ручная форма заключения остаётся доступной и работает самостоятельно.
- Схема становится частью заключения только после отдельного нажатия приёмщиком «Добавить схему в заключение» для конкретного принятого отчёта. Она передаётся в контекст исходного задания одного дома и включается в раздел актуальных схем (пункт 7 PDF/Word).
- Фото дефектов также сначала просматриваются и принимаются. Только после отдельного действия «Добавить фото дефектов в заключение» снимки именно этого адреса подставляются в штатные фото-поля формы. PDF размещает их в Приложении 3 «Фото дефектного участка»; дополнительные фото идут на продолжение Приложения 3.
- Обязательная галочка подтверждения содержания фотографий остаётся ручной: приёмщик должен проверить снимки в форме и подтвердить, что они относятся к текущему объекту.
- Схемы и дефекты других домов не подмешиваются: получение материалов заключения ограничено `taskId` адресного задания. Повторный GET без выбранного задания не выводит глобальную подборку.
- DOCX формируется из того же PDF с сохранением чертежей и фотографий как объектов изображения.

## Сохранено

- Левое меню и основное оформление ПРОФИТ.
- Распределение улиц и домов приёмщиками, расписание по датам у слесарей и трекер кнопками без GPS.
- Отдельная проверка схем CAD и фото дефектов; эти два типа отчётов остаются раздельными в данных.
- Самостоятельное ручное заполнение технического заключения без автоматических вложений.

## Обновление

Из корня проекта, где находится основной `compose.yaml`, выполни:

```bash
docker compose build --no-cache app vdgo-backend
docker compose up -d --no-deps --force-recreate app vdgo-backend
docker compose restart gateway
```

Не удаляй постоянные Docker-тома `cad_jobs`, `vdgo_postgres_data`, `vdgo_output` и `vdgo_uploads`. Полный запуск Docker на стороне разработчика в этой среде недоступен; после установки проверь вход приёмщика, единый список уведомлений и экспорт одного тестового заключения в PDF и Word.
