# ScadaProfit 4.3.19 — обновление существующего Git-проекта

## Что исправлено

1. Автоповорот страницы теперь требует одновременно `Orientation confidence >= 8.0` и `Script confidence >= 2.0`. При более слабых показателях исходная ориентация сохраняется.
2. `diagnostics.json` / checkpoint OCR содержат решение по ориентации, обе оценки OSD и применённые пороги.
3. В диагностику каждого успешного ответа Ollama добавляются SHA-256 и ограниченный фрагмент ответа (до 2000 символов).
4. Для отклонённых OCR bbox сохраняются ограниченные примеры координат, размер отправленного фрагмента, количество некорректных bbox и отсутствующих confidence.
5. Добавлены тесты для слабого OSD и сохранения ответа модели в диагностике.

**Ограничение:** это безопасное диагностическое исправление, а не завершённая реконструкция труб. Оно не обещает устранить 601 открытый конец, 100 несвязанных компонент или неточность OCR. Для этого нужна отдельная работа над геометрией и проверка на наложении с исходником.

## Установка

В корне существующего репозитория:

```bash
# 1. Резервная копия изменяемых файлов
mkdir -p backup-4.3.18
cp -a processor.py compose.yaml package.json README.md CHANGELOG-RU.md tests/test_engine.py backup-4.3.18/

# 2. Распаковать ZIP обновления в корень репозитория с заменой файлов
# (не удаляйте .env, Docker volumes и папку с заданиями)

# 3. Пересобрать и перезапустить только приложение
docker compose build app
docker compose up -d app

# 4. Проверить состояние
docker compose ps app
docker compose logs --tail=80 app
```

Не используйте `docker compose down -v`: команда может удалить том с заданиями.

## Пороги OSD

В `compose.yaml` заданы безопасные значения по умолчанию:

- `OSD_MIN_ORIENTATION_CONFIDENCE=8.0`
- `OSD_MIN_SCRIPT_CONFIDENCE=2.0`

Их можно переопределить в `.env`. Для технических чертежей не рекомендуется снижать пороги без проверки серии исходников.

## Как проверить результат

После следующего задания откройте `graph.json` и найдите:

- `diagnostics.stages` и сведения о preprocessing;
- `ocr.qwen.tile_diagnostics[*].response_preview`;
- `ocr.qwen.tile_diagnostics[*].raw_annotation_samples`;
- `ocr.qwen.tile_diagnostics[*].rejected_out_of_crop_samples`;
- `summary.preprocessing.orientation_decision` / поля подготовки изображения.

Не считайте `confidence`, возвращённый самой Qwen, доказательством правильного чтения. Сверяйте её текст с исходником и независимым OCR.
