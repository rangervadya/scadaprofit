# ScadaProfit 4.3.46 — автоматический CAD-черновик и редактор объектов

## Что изменено

- После завершения распознавания приложение автоматически создаёт и показывает редактируемый CAD-черновик даже тогда, когда строгий контроль качества чистового экспорта не пройден.
- В SVG-предпросмотр добавлен отдельный слой непроверенных кандидатов: основные трассы отображаются чёрным, кандидаты — оранжевым пунктиром. Непроверенные объекты не повышаются автоматически до чистового экспорта.
- В CAD-редактор добавлен менеджер слоёв: основные трассы, кандидаты, оборудование, подписи, размеры, узлы и исходная фотография.
- Добавлен поиск по типу, обозначению, диаметру и ID объекта; выбор строки выделяет объект на листе и прокручивает холст к нему.
- При открытии проекта холст автоматически вписывается в рабочую область; добавлена более низкая граница масштаба для крупных листов.
- У SVG-символов теперь есть стабильные ID и атрибут типа для адресного выбора и дальнейшей внешней обработки.
- Инструмент трассировки переименован в «Коррекция трассы» и явно описан как вспомогательный, а не основной сценарий.

## Важно

Эта версия исправляет показ и редактирование автоматически собранного черновика. Она не превращает каждый найденный штрих в подтверждённую трубу автоматически: сомнительные маршруты и неизвестные символы остаются на отдельном слое проверки. Чистовой инженерный документ допускается только после проверки соединений, оборудования, размеров и подписей специалистом.

## Проверки

- `node --check` для `server.js`, `manual-cad-core.js`, `public/app.js`, `public/manual-cad.js`.
- `node --test tests/manual-cad.test.js tests/manual-cad-ink-trace.test.js`: 22 теста.
- Примерный граф импортирован в CAD-модель и SVG сформирован с включёнными review-кандидатами.

## Развёртывание

Только `app`: `docker compose build app && docker compose up -d --no-deps app`.
VDGO, PostgreSQL, Ollama, Compose, Nginx, volumes и сторонние контейнеры не изменяются.
