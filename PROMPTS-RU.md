# Стандартные промпты

Стандартные промпты доступны в браузере и в файле `prompts.js`. Их можно изменять в интерфейсе: изменения хранятся в localStorage браузера и отправляются модели при следующем запросе.

- `QWEN_VISION_PROMPT` — фото → JSON `points`/`lines`.
- `QWEN_DEFAULT_ROUTE_PROMPT` — входной JSON → путь и проверяемая длина.

Главное разделение: image prompt отвечает только за точность координат и связей по пикселям; route prompt не должен менять граф, а только выбирать направленный путь из уже имеющихся связей.


## 2.9.0
Промпт изображения просит не классифицировать линии как трубы и не строить топологию. Он локализует независимые штрихи как полилинии. Граф строится сервером из каждой последовательности соседних координат.
