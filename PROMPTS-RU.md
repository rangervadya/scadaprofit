# Промпты визуальной модели в версии 4.2.7

Основные промпты сейчас хранятся в `processor.py` рядом с функциями `_qwen_annotations` и `_qwen_semantic_routes`. Старый файл `prompts.js` относится к предыдущему графовому эксперименту и не используется основным конвейером распознавания 4.2.7.

## OCR `_qwen_annotations`

Модель получает четыре перекрывающихся увеличенных фрагмента (по умолчанию сетка 2×2). Она возвращает подписи и их bbox в координатах текущего фрагмента. Сервер масштабирует координаты обратно к исходному изображению и объединяет дубликаты на стыках. Уверенные чтения экспортируются как редактируемый CAD `TEXT`; боксы умеренной уверенности могут исключать буквенные штрихи из диагностики геометрии.

## Семантические трубные маршруты `_qwen_semantic_routes`

Модель получает четыре перекрывающихся фрагмента 2×2 и для каждого должна вернуть только осевые полилинии труб: точки концов, поворотов и ответвлений. Цифры, подписи, размерные линии, выноски, стрелки и условные обозначения не должны становиться маршрутами. Сервер переводит координаты каждого фрагмента обратно в исходный лист, обрезает маршруты по неперекрывающейся области этого фрагмента и валидирует координаты и длину. Диагностические метаданные каждого ответа сохраняются в `semanticTrace.tile_diagnostics`. Если модель не указала confidence, маршрут получает условные 60% и отметку needs_review; порог по умолчанию — 35%.

## Важное ограничение

Промпт не гарантирует инженерно правильного распознавания. Маршруты Qwen являются дополнительными предложениями для слоя `QWEN_REVIEW`; основной слой `PIPE_MAIN` строится независимо по отобранным CAD-путям OpenCV. LSD/Hough-кандидаты, не прошедшие отбор, сохраняются в `DETAIL_REVIEW`. Не включайте их автоматически в основной чертёж без ручного подтверждения.
