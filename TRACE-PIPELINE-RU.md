# Конвейер реконструкции 4.2.5

1. **Нормализация:** OpenCV выравнивает освещение и строит маску чернил.
2. **Геометрические кандидаты:** LSD/Hough находят все потенциальные штрихи. Эти данные нужны для диагностики, ручной проверки и замороженного DXF-слоя `DETAIL_REVIEW`; сами по себе они не считаются трубами.
3. **Семантическая трассировка Qwen3-VL:** модель выделяет только осевые линии труб, повороты и ответвления, исключая рукописные цифры, размерные линии, выноски, стрелки и символы. Подтверждённые маршруты экспортируются на `PIPE_MAIN`.
4. **OCR Qwen3-VL:** лист обрабатывается четырьмя перекрывающимися увеличенными фрагментами. Для каждой подписи сохраняются текст, bbox и уверенность.
5. **Маскирование букв:** bbox OCR средней/высокой уверенности не дают штрихам букв и цифр попасть в линейные кандидаты. Если кандидат является непрерывным трубопроводом, проходящим через область текста, проверка продолжения сохраняет его.
6. **Редактирование:** пользователь проверяет текст и геометрию. Пересечения не становятся соединениями автоматически; ручные соединения остаются отдельными операциями.
7. **Экспорт:** SVG/DXF используют семантические маршруты Qwen. DXF содержит `PIPE_MAIN`, замороженный `DETAIL_REVIEW`, `VERIFIED_TEXT`, `SHEET` и `NOTES`.

## Режим без Ollama

Без доступной Qwen3-VL приложение не может отличить трубопровод от размерной линии, стрелки или штриха рукописной цифры. Поэтому основной лист оставляет `PIPE_MAIN` пустым и показывает предупреждение; все найденные штрихи доступны для проверки в `DETAIL_REVIEW`. Это намеренно безопаснее, чем превращать весь рисунок в ложную схему труб.
