# Аудит и изменения CAD Sketch Converter 2.6.0

## Главный вывод по версии 2.4.x

В прежнем CAD-режиме геометрия зависела от JSON, который возвращала мультимодальная модель Qwen. В реальных тестах `qwen3-vl:4b-instruct` возвращала структурно корректный JSON с пустыми массивами `nodes` и `connections`; рендерер затем не мог восстановить исходные линии. Увеличение контекста и отключение thinking не решали отсутствие геометрии.

## Что изменено в 2.6.0

1. Геометрия больше не генерируется Qwen. Её источник — исходные пиксели.
2. `processor.py` выделяет цветные чернила через HSV, с адаптивным grayscale fallback, выполняет очистку и Zhang–Suen thinning.
3. Однопиксельный скелет превращается в граф 8-соседства. Диагональные shortcuts подавляются; в пикселях с несколькими соседями выбираются наиболее прямые продолжения, а непарные ветви остаются отдельными путями.
4. OCR выполняется отдельно. Текстовые рамки применяются только как эвристика для переноса некоторых пересекающихся штрихов в слабый аннотационный слой; сами такие штрихи остаются в DXF.
5. `cad_renderer.py` создаёт SVG, PNG и DXF. DXF-слои: `CENTERLINE_PRIMARY`, `DETAIL_TRACE`, `ANNOTATION_TRACE`, `SHEET`, `NOTES`.
6. UI всегда помечает результат «НУЖНА ПРОВЕРКА». Он не объявляет пиксельную трассировку завершённой инженерной CAD-моделью.

## Что по-прежнему не гарантируется

- Определение, являются ли пересечения реальными соединениями труб.
- Разделение труб, размерных линий, стрелок и рукописных символов во всех случаях.
- Чтение всех чисел/диаметров.
- Масштаб в миллиметрах без калибровочного размера.
- Полное отсутствие пропусков и ложных штрихов.

Версия 2.6.0 — редактируемая векторная трассировка исходного рисунка, а не автоматический инженерный проект. Перед применением нужно сверять оригинал.

## Тестирование в пакете

`npm run check` проверяет синтаксис JS/Python и запускает тесты на искусственных эскизах: синий штрих с углом/ответвлением и grayscale fallback. Дополнительно выполнен локальный smoke-test на пользовательском JPEG 1280×906 px: созданы PNG/SVG/DXF. Docker daemon в среде сборки помощника отсутствовал, поэтому реальную сборку контейнера на сервере следует проверить после установки.


## Дополнение 2.6.0 — лаборатория Qwen JSON

Добавлены отдельные API `/api/qwen-extract` и `/api/qwen-route`. Первый сохраняет raw content модели при извлечении точек/связей из фото. Второй передаёт редактируемый граф и большой маршрутный промпт в Qwen. Браузерная SVG-панель рисует направленные связи напрямую по JSON и позволяет пошагово подсветить каждый сегмент. Server-side validation независимо сверяет идентификаторы, границы координат, ссылки, направленность пути и вычисленную длину. Основной OpenCV pipeline 2.5.0 сохранён без зависимости от Qwen.
