# Технический аудит CAD Reconstruction Engine 4.3.3

## Основание исправлений

Использованы диагностические данные задания `d0e2c3d8-82d2-4b68-bbe3-ffb573c5ce7c`, предоставленные пользователем.

## Изменения 4.3.3

1. `_confirmed_text_boxes()` применяет источнико-зависимые пороги: `qwen3-vl >=25`, `qwen3-vl-block` — все выделенные строки, `tesseract >=55`. Непринятые OCR-объекты сохраняются в `TEXT_REVIEW`, но слабые рамки Tesseract не вырезают геометрию автоматически.
2. Pipe и OCR обработка по умолчанию использует сетку 3x3. Предел Qwen pipe routes увеличен 48 -> 64 на фрагмент, с диагностикой достижения предела.
3. `_build_join_candidates()` исключает самостыковку одного edge, присоединение endpoint к внутренней части другого edge, пары с боковым смещением и уже связанные компоненты. Подсказки стыковок не меняют геометрию автоматически.
4. Добавлены синтетические тесты на политику OCR-маски и ложные/настоящие кандидаты соединения.
5. Стили интерфейса и существующие слои SVG/DXF сохранены.
