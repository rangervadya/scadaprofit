# Технический аудит CAD Reconstruction Engine 4.2.7

## Исправления 4.2.7
- Семантическая трассировка труб разделена на перекрывающиеся фрагменты 2×2.
- Координаты фрагментов возвращаются в систему исходного изображения; в экспорт идёт только неперекрывающаяся область каждой плитки.
- В `graph.json` добавлены метаданные ответа каждой плитки: завершение генерации, счётчики токенов, ключи JSON и количество найденных/принятых маршрутов и аннотаций. Сам распознанный текст не записывается в диагностические метаданные.
- OCR понимает распространённые альтернативные ключи JSON и выводит отдельный статус, если все четыре плитки успешно обработаны, но текст не найден.

## Ограничения
Qwen3-VL 4B может не распознать слабый почерк или условные обозначения. Разбиение уменьшает сложность отдельного запроса, но не гарантирует правильное распознавание. Слой `PIPE_MAIN` остаётся пустым, если модель не вернула проверяемые маршруты; пиксельные кандидаты не повышаются автоматически до подтверждённой геометрии.

# Технический аудит CAD Reconstruction Engine 4.2.7

## Исправления 4.2.7

- Маршруты Qwen без поля `confidence` больше не отбрасываются: они получают условную уверенность 60% и метку `needs_review`.
- Поддерживаются варианты ответа с объектами маршрутов, объектами `points` и обычными массивами координат.
- Диагностика проверяет доступность Ollama и наличие модели; конкретная ошибка и команда исправления доступны в `/api/health` и `semanticTrace`.
- Порог маршрутов по умолчанию — 35%, вместо прежнего жёсткого 68%.

## Текущий принцип работы

В версии 4.2.7 конвейер разделён на три независимых результата:

1. **Семантические маршруты труб.** Qwen3-VL через локальную Ollama получает изображение и должен вернуть JSON с осевыми полилиниями, реальными углами и ответвлениями. Только эти маршруты попадают в основной слой `PIPE_MAIN`.
2. **OCR надписей.** Qwen3-VL анализирует перекрывающиеся увеличенные фрагменты листа. Tesseract служит дополнительным источником. Подтверждённые надписи экспортируются как редактируемые CAD `TEXT`; текстовые боксы умеренной уверенности используются для подавления буквенных штрихов в диагностических линейных кандидатах.
3. **Диагностическая геометрия.** LSD/Hough OpenCV выделяют пиксельные отрезки для просмотра и ручной проверки. Они не являются подтверждёнными трубами и сохраняются на замороженном слое DXF `DETAIL_REVIEW`.

## Безопасное поведение при сбое модели

Если Ollama недоступна, модель не вернула валидный JSON или не нашла маршруты, основной слой `PIPE_MAIN` остаётся пустым. Приложение не должно автоматически превращать пиксельные кандидаты в трубопроводную схему. На листе показывается предупреждение, кандидаты доступны в исходном оверлее и `DETAIL_REVIEW`.

## Ограничения

- Qwen3-VL может пропустить отдельную трубу, неверно определить ответвление или поставить неточные координаты.
- OCR может пропустить рукописную цифру или неверно прочитать её.
- Пересечения линий не считаются автоматическим соединением.
- Без калибровочного размера физический масштаб в миллиметрах неизвестен.
- Результат остаётся предварительной векторной реконструкцией и требует сверки инженером с оригиналом.

## Проверки

`npm run check` выполняет проверку синтаксиса JavaScript и Python и запускает 27 автоматических тестов, включая тесты масштабирования OCR-фрагментов, координат семантических маршрутов и запрет продвижения сырых пиксельных кандидатов в `PIPE_MAIN`. Эти тесты используют имитацию ответа Ollama. Полноценный запуск Docker и реальной модели Qwen3-VL в среде сборки не выполнялся.
