# ScadaProfit. Пробное обучение на растрах

Модель MLP на CPU прогнозирует карту штрихов в разрешении 64×64.
Она проверяет, даёт ли эскиз сигнал для восстановления общего расположения
линий. На выходе нет CAD-объектов, текста и графа соединений. Пилот не
подключён к ScadaProfit.

Использованы 89 предполагаемых пар с 26 адресов. В пределах адреса страницы
PDF сопоставлены с JPG по порядку. Соответствие по каждому подъезду отдельно
не подтверждалось. Контрольная выборка отделена по адресу. В metrics.json
метрика ink_f1 сравнивает пиксели темнее заданного порога. Она не оценивает
назначение линий или сохранение веток. Оптимизатор остановился по лимиту
итераций. Сравнение выполнено со средним изображением обучающей выборки.

## Повтор запуска

Нужны Python 3.10 или новее, архив заказчика и scadaprofit-dataset-index.csv.

```sh
python -m pip install pymupdf pillow numpy scikit-learn joblib
python train.py '/path/to/cad-sketch-converter-docker-2.2(2).zip' scadaprofit-dataset-index.csv output
```

Модель сохранена в формате joblib. Загружайте этот формат только из доверенного источника.
